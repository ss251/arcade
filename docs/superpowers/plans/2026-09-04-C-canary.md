# Plan C — Pay-tested listings with auto-delist (M3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A hub-owned buyer key buys every listing on an interval through the normal paid path, records the outcome as durable per-listing evidence, hides any listing that fails three pay-tests in a row from every discovery surface until a runner reconnects and a canary passes, and shows the result on the marketplace.

**Architecture:** The canary is a buyer like any other — it calls `callSkill` from `@arcade/buyer` against the hub's own public URL, so it exercises the 402, the signature, the runner, the output schema and the settlement exactly as a stranger would; there is no privileged in-process shortcut, because a pay-test that skips the paid path tests nothing that is in doubt. Its outcomes are appended to a `pay_tests` history in sqlite keyed by `skillId + seller`, and `delisted` is **derived** from the trailing run of failures rather than stored as a flag — which is what makes relisting fall out for free (a passing row resets the run) and what makes the verdict survive both a hub restart and a runner reconnect, since listings themselves are deliberately not persisted. Discovery documents filter on that derived flag by construction.

**Tech Stack:** Bun 1.3, TypeScript, Effect 3.22 (`Effect.gen`, `Schedule.spaced`, `Effect.forkScoped`, Effect Schema), `bun:sqlite`, viem 2.x, vitest 3 + `bun test` for `.bun.test.ts`.

```ts
// apps/hub/src/canary-input.ts
import { parsePrice, type PublicListing } from "@arcade/core"
import { validateOutput } from "./validate.ts"

/**
 * What the canary buyer should send, and when it must not send anything at all.
 *
 * A pay-test is only evidence if the input is real, so the seller's declared `canaryInput`
 * wins. The derived fallback exists so an undeclared listing is still tested where that is
 * possible — but it deliberately REFUSES rather than guesses: a `pattern` we cannot satisfy
 * by construction would produce a 400 every interval and delist a working listing for the
 * hub's own inability to invent an address. Refusing produces "not pay-tested" on the page,
 * which is true, instead of "failed", which would not be.
 */

export type Example =
  | { readonly ok: true; readonly value: unknown }
  | { readonly ok: false; readonly why: string }

const no = (why: string): Example => ({ ok: false, why })

export const exampleFromSchema = (schema: unknown): Example => {
  if (schema === null || typeof schema !== "object" || Array.isArray(schema)) {
    return no("schema is not an object")
  }
  const s = schema as Record<string, unknown>

  // A declared example is always better than a constructed one.
  const examples = s["examples"]
  if (Array.isArray(examples) && examples.length > 0) return { ok: true, value: examples[0] }
  if ("example" in s) return { ok: true, value: s["example"] }
  if ("default" in s) return { ok: true, value: s["default"] }
  if ("const" in s) return { ok: true, value: s["const"] }
  const en = s["enum"]
  if (Array.isArray(en) && en.length > 0) return { ok: true, value: en[0] }

  const raw = s["type"]
  const type =
    typeof raw === "string" ? raw : Array.isArray(raw) && typeof raw[0] === "string" ? raw[0] : undefined

  switch (type) {
    case undefined:
      // An untyped schema constrains nothing, so an empty object satisfies it.
      return { ok: true, value: {} }
    case "object": {
      const props = (typeof s["properties"] === "object" && s["properties"] !== null
        ? s["properties"]
        : {}) as Record<string, unknown>
      const required = Array.isArray(s["required"]) ? (s["required"] as ReadonlyArray<string>) : []
      const out: Record<string, unknown> = {}
      for (const key of required) {
        const sub = props[key]
        if (sub === undefined) return no(`required property "${key}" has no schema to derive from`)
        const v = exampleFromSchema(sub)
        if (!v.ok) return no(`required property "${key}": ${v.why}`)
        out[key] = v.value
      }
      return { ok: true, value: out }
    }
    case "array":
      // `minItems` would need an element example; only the empty case is safe to assume.
      return typeof s["minItems"] === "number" && (s["minItems"] as number) > 0
        ? no("array requires items we cannot invent")
        : { ok: true, value: [] }
    case "string": {
      if (typeof s["pattern"] === "string") return no("string has a pattern we cannot satisfy by construction")
      if (typeof s["format"] === "string") return no(`string has format "${String(s["format"])}" we cannot satisfy`)
      const min = typeof s["minLength"] === "number" ? (s["minLength"] as number) : 1
      const max = typeof s["maxLength"] === "number" ? (s["maxLength"] as number) : Math.max(min, 1)
      const len = Math.max(1, Math.min(Math.max(min, 1), max))
      return { ok: true, value: "x".repeat(len) }
    }
    case "integer":
    case "number": {
      const min = typeof s["minimum"] === "number" ? (s["minimum"] as number) : 0
      const max = typeof s["maximum"] === "number" ? (s["maximum"] as number) : min
      return { ok: true, value: Math.min(min, max) }
    }
    case "boolean":
      return { ok: true, value: false }
    case "null":
      return { ok: true, value: null }
    default:
      return no(`unsupported type "${type}"`)
  }
}

/**
 * The input for one pay-test. Whatever the source, it is validated against the listing's
 * own `inputSchema` first — a seller whose declared `canaryInput` does not satisfy their
 * own schema would otherwise be delisted by the input gate for a mistake nothing named.
 */
export const canaryInputFor = (listing: PublicListing): Example => {
  const declared = (listing as { canaryInput?: unknown }).canaryInput
  if (declared !== undefined) {
    return validateOutput(declared, listing.inputSchema)
      ? { ok: true, value: declared }
      : no("the declared canaryInput does not satisfy this listing's own inputSchema")
  }
  const derived = exampleFromSchema(listing.inputSchema)
  if (!derived.ok) return derived
  return validateOutput(derived.value, listing.inputSchema)
    ? derived
    : no("no canaryInput is declared and no example derived from inputSchema satisfies it")
}

/**
 * Why this listing is not pay-tested, as a sentence for the page — or `null` when it is.
 * The hub declines to spend more than its cap on an automated probe; that is a fact about
 * the hub, so it is stated as one rather than shown as a failing listing.
 */
export const payTestSkipReason = (listing: PublicListing, capAtomic: bigint): string | null => {
  if (parsePrice(listing.price) > capAtomic) {
    return "not pay-tested — priced above this hub's canary cap, so the hub does not buy it automatically"
  }
  const input = canaryInputFor(listing)
  return input.ok
    ? null
    : `not pay-tested — ${input.why}. Declare a \`canaryInput\` in arcade.json to enable pay-testing.`
}
```

```ts
/**
 * PAY-TESTS.
 *
 * `delisted` is DERIVED from the trailing run of failures rather than stored as a flag,
 * and that is the whole design. A stored flag would need clearing, and the one moment it
 * must not be cleared is the moment it is most tempting to — when a runner reconnects,
 * which is exactly when a dead listing reappears looking healthy. Deriving it means
 * reconnecting changes nothing and a PASSING pay-test changes everything, which is the
 * rule the spec states.
 *
 * Keyed by skillId + seller because a skill id is only unique per seller's announcement;
 * a different seller announcing the same id inherits nothing.
 */
export interface PayTest {
  readonly atMs: number
  /** The job the pay-test created. Empty when the hub served no job at all (nothing listed). */
  readonly jobId: string
  readonly settleTx?: string | undefined
  readonly ok: boolean
}

export interface PayTestRow extends PayTest {
  readonly skillId: string
  readonly seller: string
  /** Verbatim reason, for the evidence script and the log. Not shown on the marketplace row. */
  readonly reason: string
}

export interface PayTestState {
  readonly last?: PayTest | undefined
  readonly consecutiveFailures: number
  readonly delisted: boolean
}

/** Three in a row, per the spec. One failure is a flake; three is a dead listing. */
export const DELIST_AFTER = 3
/** How much history the working set keeps per listing. sqlite keeps more (see store-sqlite.ts). */
export const PAY_TEST_HISTORY = 20

export const payTestKey = (skillId: string, seller: string): string =>
  `${skillId}\u0000${seller.toLowerCase()}`

export const payTestStateOf = (
  history: ReadonlyArray<PayTestRow>,
  threshold: number = DELIST_AFTER
): PayTestState => {
  let consecutiveFailures = 0
  for (let i = history.length - 1; i >= 0; i--) {
    if (history[i]!.ok) break
    consecutiveFailures++
  }
  const last = history[history.length - 1]
  return {
    ...(last === undefined
      ? {}
      : {
          last: {
            atMs: last.atMs,
            jobId: last.jobId,
            ok: last.ok,
            ...(last.settleTx === undefined ? {} : { settleTx: last.settleTx })
          }
        }),
    consecutiveFailures,
    delisted: consecutiveFailures >= threshold
  }
}

const decorate = (rec: ListingRecord, st: PayTestState): ListingRecord => ({
  ...rec,
  ...(st.last === undefined ? {} : { payTested: st.last }),
  delisted: st.delisted
})
```

```ts
// apps/hub/src/canary.ts
import { Effect, Schedule } from "effect"
import type { Account } from "viem"
import { privateKeyToAccount } from "viem/accounts"
import { formatPrice, parsePrice, type PublicListing } from "@arcade/core"
import { callSkill } from "@arcade/buyer"
import { StoreTag, type ListingRecord, type PayTestState } from "./store.ts"
import { canaryInputFor, payTestSkipReason } from "./canary-input.ts"

/**
 * THE CANARY.
 *
 * A hub-owned buyer key buys every listing once per interval, at the listed price, through
 * the ordinary paid path — a real 402, a real signature, the seller's real runner, the real
 * output schema, a real settlement. There is deliberately NO in-process shortcut: a
 * pay-test that skipped the payment would prove only the part nobody doubts, and the
 * failures worth catching (an expired API key, a dead runner, an output that stopped
 * validating, a splitter that reverts) all live in the part it would have skipped.
 *
 * Three consecutive failures hide the listing. The verdict is derived from the persisted
 * history (`store.ts`), so it survives a restart and a runner reconnect, and one passing
 * pay-test brings the listing back.
 *
 * Cost is bounded and stated: one call per listing per interval, at the listed price,
 * skipped above `ARCADE_CANARY_MAX_PRICE`. Failures cost nothing at all — nothing settles.
 */

export interface CanaryTarget {
  readonly skillId: string
  readonly seller: string
  /** Absent when no runner is currently serving this skill. */
  readonly listing?: PublicListing | undefined
  readonly lastAtMs: number | null
  readonly delisted: boolean
}

export type BuyResult = { readonly ok: boolean; readonly jobId: string; readonly settleTx?: string; readonly reason: string }
/** `null` means "skipped" — record nothing rather than inventing a verdict. */
export type BuyFn = (t: CanaryTarget) => Effect.Effect<BuyResult | null>

export interface CanaryConfig {
  readonly hubUrl: string
  readonly account: Account
  readonly intervalMs: number
  readonly tickMs: number
  readonly maxPriceAtomic: bigint
  readonly buy: BuyFn
  readonly now?: () => number
}

const UNITS: Record<string, number> = { ms: 1, s: 1_000, m: 60_000, h: 3_600_000, d: 86_400_000 }

/** `24h`, `10m`, `45s`, `250ms`, or a bare number of SECONDS. */
export const parseInterval = (text: string): number => {
  const m = /^(\d+)(ms|s|m|h|d)?$/.exec(text.trim())
  if (m === null) throw new Error(`ARCADE_CANARY_INTERVAL: cannot read "${text}" — use e.g. 24h, 10m, 45s`)
  return Number(m[1]) * (UNITS[m[2] ?? "s"] ?? 1_000)
}

/**
 * Live listings plus every skill the hub has ever pay-tested.
 *
 * The second half matters: when a runner dies its listing is dropped from the store
 * entirely, so a live-only view would have nothing to fail and the listing would come back
 * unquestioned on reconnect. Keeping the historical key alive is what makes "runner
 * offline" a pay-test failure rather than a blind spot.
 */
export const mergeTargets = (
  live: ReadonlyArray<ListingRecord>,
  known: ReadonlyArray<{ readonly skillId: string; readonly seller: string; readonly state: PayTestState }>
): ReadonlyArray<CanaryTarget> => {
  const out = new Map<string, CanaryTarget>()
  for (const k of known) {
    out.set(`${k.skillId}\u0000${k.seller.toLowerCase()}`, {
      skillId: k.skillId,
      seller: k.seller,
      lastAtMs: k.state.last?.atMs ?? null,
      delisted: k.state.delisted
    })
  }
  for (const rec of live) {
    const key = `${rec.listing.id}\u0000${rec.seller.toLowerCase()}`
    out.set(key, {
      skillId: rec.listing.id,
      seller: rec.seller,
      listing: rec.listing,
      lastAtMs: rec.payTested?.atMs ?? out.get(key)?.lastAtMs ?? null,
      delisted: rec.delisted === true
    })
  }
  return [...out.values()]
}

export const dueTargets = (
  nowMs: number,
  intervalMs: number,
  targets: ReadonlyArray<CanaryTarget>
): ReadonlyArray<CanaryTarget> =>
  targets.filter((t) => {
    // A delisted skill with no runner has nothing left to say: a fourth failure changes no
    // verdict and costs a request every tick. It becomes due again the moment a runner
    // re-announces it, which is exactly the spec's "until a runner reconnects".
    if (t.listing === undefined && t.delisted) return false
    return t.lastAtMs === null || nowMs - t.lastAtMs >= intervalMs
  })

/** The real buy: `callSkill`, against this hub's own public URL. */
export const buyViaCallSkill = (cfg: Omit<CanaryConfig, "buy">): BuyFn => (t) =>
  Effect.gen(function* () {
    if (t.listing !== undefined) {
      const skip = payTestSkipReason(t.listing, cfg.maxPriceAtomic)
      if (skip !== null) return null
      const input = canaryInputFor(t.listing)
      if (!input.ok) return null

      const out = yield* callSkill({
        hubUrl: cfg.hubUrl,
        seller: t.seller,
        skillId: t.skillId,
        input: input.value,
        account: cfg.account,
        maxAmountAtomic: parsePrice(t.listing.price),
        pollIntervalMs: 1_000,
        maxWaitMs: (t.listing.bounds.timeoutSec + 30) * 1_000
      })
      const r = out.receipt as { settled?: boolean; settleTx?: string; reason?: string }
      return {
        ok: r.settled === true,
        jobId: out.jobId ?? "",
        ...(typeof r.settleTx === "string" ? { settleTx: r.settleTx } : {}),
        reason: r.settled === true ? "ok" : `not settled: ${r.reason ?? out.status}`
      }
    }

    // No live listing: buy it anyway and let the hub answer. The 404 IS the evidence — this
    // hub is serving nothing for a skill it previously pay-tested.
    yield* callSkill({
      hubUrl: cfg.hubUrl,
      seller: t.seller,
      skillId: t.skillId,
      input: {},
      account: cfg.account,
      maxAmountAtomic: cfg.maxPriceAtomic,
      pollIntervalMs: 1_000,
      maxWaitMs: 30_000
    })
    return { ok: false, jobId: "", reason: "no live listing — the hub served nothing" }
  }).pipe(
    // Any failure of the buy IS the listing failing to be buyable. Never let it escape:
    // this runs in a fiber alongside the server.
    Effect.catchAllCause((cause) =>
      Effect.succeed({
        ok: false,
        jobId: "",
        reason: `pay-test failed: ${String(cause).slice(0, 200)}`
      })
    )
  )

/** One pass: buy everything that is due, record every verdict. */
export const canaryTick = (cfg: CanaryConfig) =>
  Effect.gen(function* () {
    const store = yield* StoreTag
    const now = cfg.now ?? Date.now
    const targets = dueTargets(now(), cfg.intervalMs, mergeTargets(yield* store.allListings, yield* store.allPayTested))

    for (const t of targets) {
      const result = yield* cfg
        .buy(t)
        .pipe(
          Effect.catchAllCause((cause) =>
            Effect.succeed({ ok: false, jobId: "", reason: `pay-test failed: ${String(cause).slice(0, 200)}` })
          )
        )
      if (result === null) continue
      yield* store.recordPayTest({
        skillId: t.skillId,
        seller: t.seller,
        atMs: now(),
        jobId: result.jobId,
        ok: result.ok,
        reason: result.reason,
        ...(result.settleTx === undefined ? {} : { settleTx: result.settleTx })
      })
      yield* Effect.sync(() =>
        console.log(
          `[canary] ${t.skillId} ${result.ok ? "pass" : "FAIL"} ${result.reason}` +
            (result.settleTx === undefined ? "" : ` tx=${result.settleTx}`)
        )
      )
    }
  })

/** The fiber body. A tick can never kill it. */
export const canaryLoop = (cfg: CanaryConfig) =>
  canaryTick(cfg).pipe(
    Effect.catchAllCause((cause) => Effect.sync(() => console.error("[canary] tick crashed", cause))),
    Effect.repeat(Schedule.spaced(`${cfg.tickMs} millis`)),
    Effect.asVoid
  )

/**
 * Configuration from the environment. `undefined` when `ARCADE_CANARY_KEY` is unset, which
 * is the correct default on a laptop: the canary spends real USDC, so it is opt-in, and the
 * page says "not pay-tested" rather than claiming a test that never ran.
 */
export const canaryFromEnv = (hubUrl: string): CanaryConfig | undefined => {
  const key = process.env["ARCADE_CANARY_KEY"]
  if (key === undefined || key === "") return undefined
  const account = privateKeyToAccount(key as `0x${string}`)
  const intervalMs = parseInterval(process.env["ARCADE_CANARY_INTERVAL"] ?? "24h")
  const maxPriceAtomic = parsePrice(process.env["ARCADE_CANARY_MAX_PRICE"] ?? "$0.25")
  const tickMs = Math.max(1_000, Math.min(parseInterval(process.env["ARCADE_CANARY_TICK"] ?? "30s"), intervalMs))
  const base = { hubUrl, account, intervalMs, tickMs, maxPriceAtomic }
  console.log(
    `[canary] on — buyer ${account.address}, every ${process.env["ARCADE_CANARY_INTERVAL"] ?? "24h"} per listing, ` +
      `cap ${formatPrice(maxPriceAtomic)}, against ${hubUrl}`
  )
  return { ...base, buy: buyViaCallSkill(base) }
}
```

- [ ] **Step 1: Write the script**

```bash
#!/usr/bin/env bash
# Pay-tested listings, proven end to end on Arc testnet.
#
# The claim is narrow and checkable: a listing that stops working stops being advertised,
# and it comes back only by being bought successfully — not by its runner reconnecting.
# So this kills a runner, waits for three failed pay-tests, restarts the runner, and shows
# the listing is STILL hidden until the next canary purchase settles.
#
#   ARCADE_CANARY_KEY       funded Arc testnet key the hub buys with
#   ARCADE_FACILITATOR_KEY  funded Arc testnet key the hub settles with
#   SELLER                  address that receives USDC
#
# usage:
#   ARCADE_CANARY_KEY=0x… ARCADE_FACILITATOR_KEY=0x… SELLER=0x… bash scripts/e2e-canary.sh
set -euo pipefail

: "${ARCADE_CANARY_KEY:?set a funded Arc testnet key for the canary buyer}"
: "${ARCADE_FACILITATOR_KEY:?set a funded Arc testnet key for the facilitator}"
: "${SELLER:?set SELLER to the address that receives USDC}"

PORT="${PORT:-8791}"
SKILL="${SKILL:-usdc-flow-check}"
HUB="http://localhost:$PORT"
DB="$(mktemp -d)/canary.db"
HUB_LOG=$(mktemp)
RUNNER_LOG=$(mktemp)

cleanup() {
  kill "${RUNNER_PID:-0}" 2>/dev/null || true
  kill "${HUB_PID:-0}" 2>/dev/null || true
}
trap cleanup EXIT

start_runner() {
  bun run packages/runner/src/cli.ts runner start >> "$RUNNER_LOG" 2>&1 &
  RUNNER_PID=$!
}

# `jq` is not assumed; bun reads the JSON.
field() { bun -e "const j=await Bun.stdin.json(); console.log(String($1))"; }

echo "== hub (canary every 15s, tick every 5s) =="
ARCADE_RAIL=eip3009 \
ARCADE_DB="$DB" \
ARCADE_HUB_SECRET=e2e-canary \
ARCADE_CANARY_INTERVAL=15s \
ARCADE_CANARY_TICK=5s \
PORT=$PORT \
  bun run apps/hub/src/server.ts > "$HUB_LOG" 2>&1 &
HUB_PID=$!
sleep 3
curl -sf "$HUB/healthz" > /dev/null && echo "hub up"

echo "== runner =="
bun run packages/runner/src/cli.ts runner init --seller "$SELLER" --hub "$HUB" > /dev/null
start_runner
sleep 5
curl -sf "$HUB/listings" | field 'j.length + " listing(s)"'

echo "== 1. the first pay-test settles =="
for _ in $(seq 1 24); do
  OK=$(curl -sf "$HUB/listings/$SKILL" | field 'j.payTested && j.payTested.ok')
  [ "$OK" = "true" ] && break
  sleep 5
done
[ "$OK" = "true" ] || { echo "FAIL: no passing pay-test within 2 minutes"; tail -40 "$HUB_LOG"; exit 1; }
TX1=$(curl -sf "$HUB/listings/$SKILL" | field 'j.payTested.settleTx')
echo "pay-test settled: https://testnet.arcscan.app/tx/$TX1"

echo "== 2. kill the runner; three failed pay-tests must delist it =="
kill "$RUNNER_PID"; RUNNER_PID=""
for _ in $(seq 1 24); do
  DELISTED=$(curl -sf "$HUB/listings/$SKILL" | field 'j.delisted')
  [ "$DELISTED" = "true" ] && break
  sleep 5
done
[ "$DELISTED" = "true" ] || { echo "FAIL: not delisted after the runner died"; grep canary "$HUB_LOG" | tail -20; exit 1; }

echo "-- hidden from every discovery surface --"
curl -sf "$HUB/listings"          | field "j.some(l=>l.id==='$SKILL')" | grep -qx false || { echo "FAIL: still in /listings"; exit 1; }
curl -sf "$HUB/openapi.json"      | field "Object.keys(j.paths).some(p=>p.includes('$SKILL'))" | grep -qx false || { echo "FAIL: still in /openapi.json"; exit 1; }
curl -sf "$HUB/.well-known/x402"  | field "j.resources.some(r=>r.resource.includes('$SKILL'))" | grep -qx false || { echo "FAIL: still in /.well-known/x402"; exit 1; }
curl -sf "$HUB/skill.md" | grep -q "$SKILL" && { echo "FAIL: still in /skill.md"; exit 1; }
curl -sf "$HUB/skill/$SKILL" | grep -q "delisted: failed pay-test" || { echo "FAIL: the listing page does not say why"; exit 1; }
echo "delisted, and the page says why"

echo "== 3. reconnecting is NOT enough =="
start_runner
sleep 6
STILL=$(curl -sf "$HUB/listings/$SKILL" | field 'j.delisted')
[ "$STILL" = "true" ] || { echo "FAIL: reconnecting cleared the verdict — only a passing pay-test may"; exit 1; }
echo "runner is back and the listing is still hidden"

echo "== 4. a passing pay-test relists it =="
for _ in $(seq 1 24); do

curl -sf "$HUB/listings" | field "j.some(l=>l.id==='$SKILL')" | grep -qx true || { echo "FAIL: relisted but absent from /listings"; exit 1; }

echo
echo "PASS"
echo "  first pay-test   https://testnet.arcscan.app/tx/$TX1"
echo "  relisting        https://testnet.arcscan.app/tx/$TX2"
```

- **Ambiguities resolved.** (1) The spec says "runner offline" counts as a pay-test failure, but the hub *drops* a listing when its runner disconnects (`store.ts:117`), so a live-only canary would have nothing to fail. Resolved by keying the persisted history on skillId+seller and merging it with live listings (`mergeTargets`), so an absent listing is probed, fails, and delists — and stops being probed once delisted, until a runner re-announces it.
