# Plan E — ENSv2 namespaces (M5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every ARCADE seller and every listing a real ENSv2 name on Sepolia — `<skill>.<seller>.<parent>.eth` — whose records are the authority over where a buyer's money goes, whose expiry *is* the runner's liveness, and whose daemon key can rotate a price and nothing else.

**Architecture:** Three layers, no new trust. (1) `scripts/ens-setup.ts` is a one-shot owner-key script that registers the parent 2LD through the ETHRegistrar's commit/reveal, deploys a SellerRegistry and a per-seller SkillRegistry through `VerifiableFactory.deployProxy`, mints non-transferable skill subnames with `expiry = now + ARCADE_ENS_TTL`, writes the ENSIP-25/26 + `arcade.*` text records in one resolver `multicall`, and delegates exactly one text key (`arcade.priceAtomic`) to the seller daemon via `authorizeTextRoles`. (2) `packages/runner/src/ens.ts` renews those subnames on the daemon's heartbeat cycle and pushes a price change; a dead runner stops renewing and the name expires on its own. (3) `packages/buyer/src/ens-policy.ts` resolves `arcade.endpoint` / `arcade.payTo` / `arcade.chain` with stock viem `getEnsText` on Sepolia and refuses `ens_payto_mismatch` **before** signing when the 402 disagrees, `ens_name_expired` when the name resolves to nothing. Settlement still happens on Arc; ENS is naming and authorisation, never a settlement dependency.

**Tech Stack:** Bun 1.3, TypeScript, Effect 3.22 (Effect Schema, `Data.TaggedError`), viem **2.55.8** (installed — `node -e "console.log(require('viem/package.json').version)"` → `2.55.8`, well above the ENSv2 read floor of 2.35.0), `viem/ens` (`namehash`, `labelhash`, `normalize`, `packetToBytes`, `getEnsText`), vitest 3 for `*.test.ts`, `bun test` for `*.bun.test.ts`.

```ts
import { encodeAbiParameters, keccak256, stringToHex, toHex } from "viem"
import { labelhash, namehash, normalize, packetToBytes } from "viem/ens"

/**
 * ENSv2 (Sepolia) — the one module every ARCADE surface shares.
 *
 * Naming lives on Sepolia because ENSv2 exists nowhere else; settlement stays on Arc.
 * That split is the point rather than a workaround: ENSIP-26 frames a name as "a single,
 * multichain identity for an AI agent", and ENSIP-25 uses ERC-7930 interoperable addresses
 * precisely so a name can reference a registry on another chain. `arcade.chain` and
 * `arcade.payTo` make the link machine-checkable — the buyer refuses to sign when the 402
 * disagrees with what the name says, so ENS is the AUTHORITY over the payment destination,
 * not a label printed next to it.
 *
 * Contracts-v2 is beta ("not yet final and may change prior to mainnet deployment"), so no
 * address appears in this file: `config/ens/sepolia.json` carries both live deployment sets
 * and `resolveEnsDeployment` picks one by walking the root registry at runtime.
 */

export const ENS_SEPOLIA_CHAIN_ID = 11155111

/**
 * Text records on `<skill>.<seller>.<parent>.eth`.
 *
 * `arcade.*` are ENSIP-5 namespaced custom keys (namespaced so they cannot collide with a
 * future standard key); `agent-*` are ENSIP-26, so a generic agent that has never heard of
 * ARCADE can still find the endpoint.
 */
export const ENS_TEXT_KEYS = {
  payTo: "arcade.payTo",
  chain: "arcade.chain",
  /** 6-decimal atomic USDC as a decimal string. Never a float. */
  priceAtomic: "arcade.priceAtomic",
  endpoint: "arcade.endpoint",
  web: "agent-endpoint[web]",
  mcp: "agent-endpoint[mcp]",
  context: "agent-context"
} as const

// ── ERC-7930 / ENSIP-25 ─────────────────────────────────────────────────────

/**
 * ERC-7930 interoperable address for an eip155 chain:
 * `version(2) || chainType(2) || chainRefLen(1) || chainRef || addrLen(1) || address`.
 * Verified against the ENSIP-25 worked example (mainnet, registry 0x8004A169…).
 */
export const erc7930Eip155 = (chainId: number | bigint, address: string): `0x${string}` => {
  const id = BigInt(chainId)
  if (id <= 0n) throw new Error(`erc7930Eip155: chain id must be positive, got ${String(chainId)}`)
  const ref = id.toString(16).length % 2 === 1 ? `0${id.toString(16)}` : id.toString(16)
  const addr = address.toLowerCase().replace(/^0x/, "")
  if (!/^[0-9a-f]{40}$/.test(addr)) {
    throw new Error(`erc7930Eip155: not a 20-byte address: ${address}`)
  }
  const refLen = (ref.length / 2).toString(16).padStart(2, "0")
  return `0x00010000${refLen}${ref}14${addr}`
}

/**
 * ENSIP-25 key. A non-empty value on this key is the name owner attesting that the name
 * belongs to that registry entry — the other half of ERC-8004's `agentURI` claim, so
 * neither side can be spoofed alone.
 */
export const agentRegistrationKey = (
  chainId: number | bigint,
  registry: string,
  agentId: string | number
): string => {
  const id = String(agentId)
  if (id.includes("[") || id.includes("]")) {
    throw new Error(`agentRegistrationKey: agent id must not contain a bracket: ${id}`)
  }
  return `agent-registration[${erc7930Eip155(chainId, registry)}][${id}]`
}

// ── names ───────────────────────────────────────────────────────────────────

const LABEL = /^[a-z0-9][a-z0-9-]{1,61}[a-z0-9]$/

/**
 * A DNS-safe label for a seller. An address becomes `s` + its first ten hex digits, which
 * is stable, unique enough for a marketplace, and readable in a name; a handle is
 * lowercased and hyphen-normalised.
 */
export const sellerLabelFor = (handleOrAddress: string): string => {
  const raw = handleOrAddress.trim().toLowerCase()
  const label = /^0x[0-9a-f]{40}$/.test(raw)
    ? `s${raw.slice(2, 12)}`
    : raw.replace(/[^a-z0-9-]+/g, "-").replace(/^-+|-+$/g, "")
  if (!LABEL.test(label)) {
    throw new Error(
      `"${handleOrAddress}" does not produce a usable ENS label (got "${label}"): ` +
        `3–63 characters of a–z, 0–9 and hyphens, not starting or ending with a hyphen.`
    )
  }
  return label
}

export const arcadeSellerName = (a: { readonly root: string; readonly sellerLabel: string }): string =>
  normalize(`${a.sellerLabel}.${a.root}`)

export const arcadeSkillName = (a: {
  readonly root: string
  readonly sellerLabel: string
  readonly skillId: string
}): string => normalize(`${a.skillId}.${a.sellerLabel}.${a.root}`)

/**
 * `anyId` for PermissionedRegistry. The contract accepts a labelhash, a token id or a
 * resource, so the labelhash-as-uint256 works everywhere and needs no lookup.
 */
export const labelId = (label: string): bigint => BigInt(labelhash(label))

/** DNS-encoded name — what `authorizeTextRoles` and friends take. */
export const dnsNameOf = (name: string): `0x${string}` => toHex(packetToBytes(normalize(name)))

// ── EAC roles (verbatim from the contracts, not the docs prose) ──────────────

/** `contracts/src/registry/libraries/RegistryRolesLib.sol`. Admin counterpart = role << 128. */
export const RegistryRoles = {
  REGISTRAR: 1n << 0n,
  REGISTER_RESERVED: 1n << 4n,
  SET_PARENT: 1n << 8n,
  UNREGISTER: 1n << 12n,
  RENEW: 1n << 16n,
  SET_SUBREGISTRY: 1n << 20n,
  SET_RESOLVER: 1n << 24n,
  CAN_TRANSFER_ADMIN: (1n << 28n) << 128n,
  SET_URI: 1n << 36n,
  CAN_NAME: 1n << 120n,
  UPGRADE: 1n << 124n
} as const

/** `contracts/src/resolver/libraries/PermissionedResolverLib.sol`. */
export const ResolverRoles = {
  SET_ADDR: 1n << 0n,
  SET_TEXT: 1n << 4n,
  SET_CONTENTHASH: 1n << 8n,
  SET_ALIAS: 1n << 28n,
  CLEAR: 1n << 32n,
  SET_DATA: 1n << 36n,
  UPGRADE: 1n << 124n
} as const

const admin = (role: bigint): bigint => role << 128n

/** The 64-nybble mask the UserRegistry / resolver initializers take for "everything". */
export const ALL_ROLES = BigInt(`0x${"1".repeat(64)}`)

/**
 * What a seller holds on their own `<seller>.<parent>.eth`: enough to point the name at
 * their skill registry and their resolver, and NOT `CAN_TRANSFER_ADMIN` — a seller identity
 * that can be sold to someone else is a seller identity a buyer cannot rely on.
 */
export const SELLER_SUBNAME_ROLES =
  RegistryRoles.SET_SUBREGISTRY |
  admin(RegistryRoles.SET_SUBREGISTRY) |
  RegistryRoles.SET_RESOLVER |
  admin(RegistryRoles.SET_RESOLVER) |
  RegistryRoles.RENEW |
  admin(RegistryRoles.RENEW)

/**
 * What a seller holds on `<skill>.<seller>.<parent>.eth`. `RENEW` is the liveness lever and
 * `UNREGISTER` is the delist lever; `CAN_TRANSFER_ADMIN` is deliberately absent, which is
 * ENSv2's answer to the old `CANNOT_TRANSFER` fuse — except revocable, because roles are.
 */
export const SKILL_SUBNAME_ROLES =
  RegistryRoles.RENEW |
  admin(RegistryRoles.RENEW) |
  RegistryRoles.UNREGISTER |
  admin(RegistryRoles.UNREGISTER) |
  RegistryRoles.SET_RESOLVER |
  admin(RegistryRoles.SET_RESOLVER)

// ── CREATE2 salts (canonical, shared with contracts-v2 and ens-cli) ──────────

/** `keccak256(abi.encode(keccak256("UserRegistry"), namehash(name), version))`. */
export const userRegistrySalt = (name: string, version = 0n): bigint =>
  BigInt(
    keccak256(
      encodeAbiParameters(
        [{ type: "bytes32" }, { type: "bytes32" }, { type: "uint256" }],
        [keccak256(stringToHex("UserRegistry")), namehash(normalize(name)), version]
      )
    )
  )

/**
 * `keccak256(abi.encode(keccak256("OwnedResolver"), owner, 0))` — the scheme contracts-v2's
 * setup script and the manager app both use, so a resolver is rediscoverable from the owner
 * address alone with no bookkeeping.
 */
export const ownedResolverSalt = (owner: string): bigint =>
  BigInt(
    keccak256(
      encodeAbiParameters(
        [{ type: "bytes32" }, { type: "address" }, { type: "uint256" }],
        [keccak256(stringToHex("OwnedResolver")), owner.toLowerCase() as `0x${string}`, 0n]
      )
    )
  )

// ── TTL ─────────────────────────────────────────────────────────────────────

const UNITS: Record<string, number> = { s: 1, m: 60, h: 3600, d: 86400 }

/**
 * `ARCADE_ENS_TTL` — how long a skill subname lives before the runner must renew it.
 *
 * Default 6h, 15m in the demo. The floor is a minute because the renewal loop runs on the
 * 15s heartbeat and a TTL below that would expire between two renewals, taking a live
 * listing offline for a reason the seller cannot see.
 */
export const ensTtlSeconds = (raw: string | undefined = process.env["ARCADE_ENS_TTL"]): number => {
  if (raw === undefined || raw.trim() === "") return 6 * 3600
  const m = /^(\d+)(s|m|h|d)?$/.exec(raw.trim())
  if (m === null) {
    throw new Error(`ARCADE_ENS_TTL must look like 900, 15m, 6h or 90d — got "${raw}"`)
  }
  const seconds = Number(m[1]) * (UNITS[m[2] ?? "s"] ?? 1)
  if (seconds < 60) {
    throw new Error(`ARCADE_ENS_TTL must be at least 60s (the renewal loop runs on the heartbeat) — got "${raw}"`)
  }
  return seconds
}
```

```ts
/**
 * Pick the deployment to use, by asking the chain rather than by trusting a table.
 *
 * Two parallel ENSv2 deployments are live on Sepolia and neither is a successor to the
 * other, so "the addresses in the docs" is not a fact a build can rely on. A set is
 * accepted only when its own RootRegistry says `getSubregistry("eth")` is its own
 * ETHRegistry — the same check the ENS app-developer tutorial demands ("Do not hardcode a
 * Universal Resolver address"), applied to the whole set.
 */
export const resolveEnsDeployment = async (
  reader: EnsChainReader,
  sets: ReadonlyArray<EnsDeployment> = loadEnsDeployments()

    const got = await reader
      .readContract({
        address: d.rootRegistry,
        abi: ROOT_REGISTRY_ABI,
        functionName: "getSubregistry",

        findings.push(`set ${d.set}: RootRegistry ${d.rootRegistry} unreadable (${String((e as Error)?.message ?? e)})`)
        return undefined
      })

    if (typeof got === "string" && got.toLowerCase() === d.ethRegistry.toLowerCase()) return d
    findings.push(
      `set ${d.set}: RootRegistry ${d.rootRegistry} getSubregistry("eth") = ${String(got)}, ` +
        `expected ${d.ethRegistry} (${d.source})`
    )
  }
  throw new Error(
    `no consistent ENSv2 deployment on Sepolia:\n  ${findings.join("\n  ")}\n` +
      `Update config/ens/sepolia.json from https://docs.ens.domains/learn/deployments — ` +
      `contracts-v2 is beta and its addresses move.`
  )
}
```

```ts
/**
```

```ts
 * CREATE2 salt — `keccak256(abi.encode(keccak256("UserRegistry"), namehash(name), 0))` —
```

```ts
export interface SkillRecordInput {
  readonly name: string
  readonly endpoint: string
  readonly payTo: string
  readonly caip2: string
  readonly priceAtomic: bigint
  readonly webUrl: string
  readonly mcpUrl: string
  readonly context: string
  readonly agentRegistration?: {
    readonly chainId: number | bigint
    readonly registry: string
    readonly agentId: string | number
  }
}

/**
 * Everything a name says about a listing.
 *
 * `arcade.payTo` and `arcade.chain` are the load-bearing pair: the buyer refuses to sign
 * when the 402 challenge disagrees with them, which makes the name the authority over the
 * payment destination instead of a caption next to it. `agent-context` repeats the same
 * facts as JSON under a human sentence so an ENSIP-26 agent with no ARCADE knowledge can
 * still act on the name.
 */
export const skillTextRecords = (
  a: SkillRecordInput
): ReadonlyArray<{ readonly key: string; readonly value: string }> => {
  const facts = {
    name: a.name,
    endpoint: a.endpoint,
    payTo: a.payTo,
    chain: a.caip2,
    priceAtomic: a.priceAtomic.toString(),
    protocol: "x402",
    mcp: a.mcpUrl
  }
  const records: Array<{ key: string; value: string }> = [
    { key: ENS_TEXT_KEYS.endpoint, value: a.endpoint },
    { key: ENS_TEXT_KEYS.payTo, value: a.payTo },
    { key: ENS_TEXT_KEYS.chain, value: a.caip2 },
    { key: ENS_TEXT_KEYS.priceAtomic, value: a.priceAtomic.toString() },
    { key: ENS_TEXT_KEYS.web, value: a.webUrl },
    { key: ENS_TEXT_KEYS.mcp, value: a.mcpUrl },
    { key: ENS_TEXT_KEYS.context, value: `${a.context}\n\n${JSON.stringify(facts)}` }
  ]
  if (a.agentRegistration !== undefined) {
    records.push({
      key: agentRegistrationKey(
        a.agentRegistration.chainId, a.agentRegistration.registry, a.agentRegistration.agentId
      ),
      // ENSIP-25: "the presence of a non-empty value is interpreted as an attestation".
      value: "1"
    })
  }
  return records
}

  readonly skillId: string
  readonly label: string
  readonly name: string
  readonly priceAtomic: string

  readonly universalResolver: string
  readonly sellerRegistry: string
  readonly skillRegistry: string
  readonly resolver: string

  readonly skills: ReadonlyArray<EnsSkillState>
}

export const readEnsState = async (): Promise<EnsState | undefined> => {

  if (!(await file.exists())) return undefined
  return (await file.json()) as EnsState
```

```ts
const registerSkills = async (
  d: EnsDeployment, root: string, resolver: Hex, skillRegistry: Hex
): Promise<void> => {
  const now = Math.floor(Date.now() / 1000)
  const expiry = BigInt(now + ttl)
  const state: EnsSkillState[] = []

  for (const skillId of skillIds) {
    const name = arcadeSkillName({ root, sellerLabel, skillId })

    // Liveness is the expiry. A runner that stops renewing lets its own listing lapse —
    // no heartbeat table, no reaper, no hub opinion: the name simply stops resolving.
    await send(`SkillRegistry.register(${name})`, {
      address: skillRegistry, abi: PERMISSIONED_REGISTRY_ABI, functionName: "register",
      // registry = 0x0 (a skill is a leaf), roles WITHOUT CAN_TRANSFER_ADMIN.
      args: [skillId, seller as Hex, "0x0000000000000000000000000000000000000000", resolver,
             SKILL_SUBNAME_ROLES, expiry],
      account: owner, chain: sepolia
    })

    const listing = (await (await fetch(`${hubUrl}/listings/${skillId}`)).json()) as {
      price: string; seller: string
    }
    const priceAtomic = BigInt(Math.round(Number(listing.price.replace(/[^0-9.]/g, "")) * 1e6))

    const records = skillTextRecords({
      name,
      endpoint: `${hubUrl}/x/${listing.seller}/${skillId}`,
      payTo: listing.seller,
      caip2: "eip155:5042002",
      priceAtomic,
      webUrl: `${webUrl}/skill/${skillId}`,
      mcpUrl,
      context: `${skillId} on ARCADE: a paid x402 endpoint on Arc testnet. Pay in USDC to arcade.payTo on arcade.chain; nothing settles unless the output validates against the listing's schema.`,
      ...(agentId === "" ? {} : {
        agentRegistration: {
          chainId: 5042002,
          registry: "0x8004A818BFB912233c491871b3d84c89A494BD9e",
          agentId
        }
      })
    })

    // One transaction for every record on the name. `multicall` is on the resolver itself,
    // so this is atomic: a half-written listing is not a state anyone can observe.
    const node = namehash(name)
    await send(`resolver.multicall(${records.length} records on ${name})`, {
      address: resolver, abi: PERMISSIONED_RESOLVER_ABI, functionName: "multicall",
      args: [records.map((r) => encodeFunctionData({
        abi: PERMISSIONED_RESOLVER_ABI, functionName: "setText", args: [node, r.key, r.value]
      }))],
      account: owner, chain: sepolia
    })

    if (daemon !== undefined) {
      // The two grants that make this a security story rather than a naming story.
      //
      // 1. RENEW on the registry: the daemon can keep its own name alive and nothing else.
      await send(`SkillRegistry.grantRoles(RENEW → daemon) on ${name}`, {
        address: skillRegistry, abi: PERMISSIONED_REGISTRY_ABI, functionName: "grantRoles",
        args: [labelId(skillId), RegistryRoles.RENEW, daemon], account: owner, chain: sepolia
      })
      // 2. authorizeTextRoles on ONE key: the daemon can rotate its price and cannot touch
      //    arcade.payTo. ENSv1 could not express that — the resource here is
      //    (node, keccak(textKey)), not the node.
      await send(`resolver.authorizeTextRoles(arcade.priceAtomic → daemon) on ${name}`, {
        address: resolver, abi: PERMISSIONED_RESOLVER_ABI, functionName: "authorizeTextRoles",
        args: [dnsNameOf(name), ENS_TEXT_KEYS.priceAtomic, daemon, true],
        account: owner, chain: sepolia
      })
    }

    state.push({ skillId, label: skillId, name, priceAtomic: priceAtomic.toString() })
    console.log(`  ${name} live, expires ${new Date(Number(expiry) * 1000).toISOString()}`)
  }

  const out: EnsState = {
    root, sellerLabel, seller, deploymentSet: d.set, universalResolver: d.universalResolver,
    sellerRegistry: sellerRegistryAddress, skillRegistry, resolver, ttlSeconds: ttl, skills: state
  }
  await Bun.write(ensStatePath(), `${JSON.stringify(out, null, 2)}\n`)
  console.log(`\nwrote ${ensStatePath()}`)
  console.log(`set ARCADE_ENS_ROOT=${root} on the hub and the buyer to turn resolution on.`)
}
```

```ts
import { createPublicClient, createWalletClient, http, type Hex } from "viem"
import { namehash } from "viem/ens"
import { privateKeyToAccount } from "viem/accounts"
import { sepolia } from "viem/chains"
import {
  ENS_TEXT_KEYS, PERMISSIONED_REGISTRY_ABI, PERMISSIONED_RESOLVER_ABI, labelId,
  type EnsState
} from "@arcade/core"

/**
 * Liveness as expiry.
 *
 * Every other marketplace answers "is this listing real?" with a heartbeat table someone
 * has to trust. Here the answer is on chain and negative by default: a skill subname is
 * minted with `expiry = now + ARCADE_ENS_TTL`, and the only thing keeping it alive is this
 * loop calling `renew`. Kill the runner and the name lapses on its own — `getEnsText`
 * returns nothing, the hub marks the listing expired, and a buyer resolving by name gets
 * nothing to pay. Reconnect and the next renew revives it, owner and roles restored (that
 * is ENSv2's revival semantics; a re-`register` would start a fresh token instead).
 *
 * The daemon key holds exactly two powers: `ROLE_RENEW` on its own subnames, and
 * `authorizeTextRoles` on `arcade.priceAtomic`. It cannot change `arcade.payTo`. A stolen
 * daemon key can make a listing cheaper or let it die; it cannot redirect a single cent.
 *
 * Everything here is best-effort by construction: no promise from this module is awaited by
 * a settlement path, and `tick` never throws. Sepolia going down must not take an Arc
 * marketplace offline.
 */

export interface EnsWriter {
  readonly renew: (a: {
    readonly registry: string
    readonly anyId: bigint
    readonly expiry: bigint
  }) => Promise<string>
  readonly setText: (a: {
    readonly resolver: string
    readonly node: string
    readonly key: string
    readonly value: string
  }) => Promise<string>
}

/** Renew once per quarter-TTL. The heartbeat is 15s; a tx every 15s would be absurd. */
export const RENEW_FRACTION = 4

export interface EnsLivenessArgs {
  readonly state: EnsState
  readonly writer: EnsWriter
  /** Atomic price from the live manifest, or undefined if this runner no longer serves it. */
  readonly priceAtomicFor: (skillId: string) => bigint | undefined
  readonly now?: () => number
  readonly log?: (line: string) => void
}

export const makeEnsLiveness = (a: EnsLivenessArgs) => {
  const now = a.now ?? Date.now
  const log = a.log ?? ((line: string) => console.log(line))
  const renewedAt = new Map<string, number>()
  const pricePublished = new Map<string, string>(a.state.skills.map((s) => [s.skillId, s.priceAtomic]))
  const everyMs = (a.state.ttlSeconds * 1000) / RENEW_FRACTION

  const tick = async (): Promise<void> => {
    for (const skill of a.state.skills) {
      const last = renewedAt.get(skill.skillId)
      if (last === undefined || now() - last >= everyMs) {
        try {
          const expiry = BigInt(Math.floor(now() / 1000) + a.state.ttlSeconds)
          const tx = await a.writer.renew({
            registry: a.state.skillRegistry, anyId: labelId(skill.label), expiry
          })
          // Recorded only on success, so a failed renew is retried on the next tick rather
          // than waiting out a quarter-TTL it never earned.
          renewedAt.set(skill.skillId, now())
          log(`[ens] renewed ${skill.name} until ${new Date(Number(expiry) * 1000).toISOString()} (${tx})`)
        } catch (e) {
          log(`[ens] renew ${skill.name} failed (will retry next heartbeat): ${String((e as Error)?.message ?? e)}`)
        }
      }

      const price = a.priceAtomicFor(skill.skillId)
      if (price !== undefined && price.toString() !== pricePublished.get(skill.skillId)) {
        try {
          const tx = await a.writer.setText({
            resolver: a.state.resolver,
            node: namehash(skill.name),
            key: ENS_TEXT_KEYS.priceAtomic,
            value: price.toString()
          })
          pricePublished.set(skill.skillId, price.toString())
          log(`[ens] ${skill.name} arcade.priceAtomic → ${price.toString()} (${tx})`)
        } catch (e) {
          log(`[ens] price update for ${skill.name} refused: ${String((e as Error)?.message ?? e)}`)
        }
      }
    }
  }

  return { tick, lastRenewAtMs: (skillId: string) => renewedAt.get(skillId) }
}

/** The real writer. Sepolia only — the Arc receipt-wait rule does not apply on this chain. */
export const viemEnsWriter = (privateKey: string, rpcUrl?: string): EnsWriter => {
  const account = privateKeyToAccount(privateKey as Hex)
  const transport = http(rpcUrl ?? process.env["ARCADE_ENS_RPC"] ?? undefined)
  const pub = createPublicClient({ chain: sepolia, transport })
  const wallet = createWalletClient({ account, chain: sepolia, transport })
  const confirm = async (hash: Hex): Promise<string> => {
    const rec = await pub.waitForTransactionReceipt({ hash })
    if (rec.status !== "success") throw new Error(`reverted: ${hash}`)
    return hash
  }
  return {
    renew: async (x) =>
      confirm(await wallet.writeContract({
        address: x.registry as Hex, abi: PERMISSIONED_REGISTRY_ABI, functionName: "renew",
        args: [x.anyId, x.expiry], account, chain: sepolia
      })),
    setText: async (x) =>
      confirm(await wallet.writeContract({
        address: x.resolver as Hex, abi: PERMISSIONED_RESOLVER_ABI, functionName: "setText",
        args: [x.node as Hex, x.key, x.value], account, chain: sepolia
      }))
  }
}
```

```ts
/**
 * The ENS liveness ticker, or nothing.
 *
 * Absent state or an absent key means this seller has no namespace, which is a normal
 * configuration and not an error — the runner serves exactly as it did before ENS existed.
 * A misconfiguration (state but no key) says so once, rather than renewing silently
 * nowhere.
 */
export const ensTickerFor = async (a: {
  readonly skills: ReadonlyArray<{ readonly manifest: { readonly id: string; readonly price: string } }>
  readonly log?: (line: string) => void
}): Promise<{ readonly tick: () => Promise<void> } | undefined> => {
  const log = a.log ?? ((line: string) => console.log(line))
  const state = await readEnsState().catch(() => undefined)
  if (state === undefined) return undefined
  const key = process.env["ARCADE_ENS_DAEMON_KEY"]
  if (key === undefined) {
    log(
      `[ens] ${state.skills.length} name(s) in ${ensStatePath()} but ARCADE_ENS_DAEMON_KEY is ` +
        `not set, so nothing will be renewed and they will expire in ${state.ttlSeconds}s. ` +
        `Set it to the Sepolia key ens-setup granted ROLE_RENEW.`
    )
    return undefined
  }
  const priceById = new Map(a.skills.map((s) => [s.manifest.id, parsePrice(s.manifest.price)]))
  return makeEnsLiveness({
    state,
    writer: viemEnsWriter(key),
    priceAtomicFor: (skillId) => priceById.get(skillId),
    log
  })
}
```

```ts
import { Data, Effect } from "effect"
import { createPublicClient, http } from "viem"
import { normalize } from "viem/ens"
import { sepolia } from "viem/chains"
import { ENS_TEXT_KEYS, loadEnsDeployments } from "@arcade/core"

/**
 * ENS as the authority over where money goes.
 *
 * A 402 challenge is a stranger's claim about a payee. Today a buyer signs against it
 * because there is nothing better to compare it to. With a name, there is: `arcade.payTo`
 * and `arcade.chain` were written by the name's owner through a resolver whose per-key
 * roles the seller daemon does not hold, so a compromised hub or a tampered challenge that
 * changes the payee no longer agrees with the name — and this refuses BEFORE
 * `signAuthorization`, which is the only place a refusal is worth anything.
 *
 * Reads are stock viem on Sepolia (`getEnsText` through UniversalResolverV2, with CCIP-read
 * handled by viem). ENSv2 write support in the libraries is preview-only; nothing here
 * writes.
 */

export interface EnsReader {
  readonly getEnsText: (a: {
    readonly name: string
    readonly key: string
    readonly universalResolverAddress?: `0x${string}`
  }) => Promise<string | null>
}

export class EnsNameExpired extends Data.TaggedError("EnsNameExpired")<{
  readonly name: string
  readonly key: string
  readonly detail?: string
}> {
  readonly code = "ens_name_expired"
  get message(): string {
    return (
      `${this.name} does not resolve ${this.key}. On ARCADE a name's expiry IS its liveness: ` +
      `the runner renews it while it serves, so an expired name means nobody is serving that ` +
      `listing right now. Nothing was signed.`
    )
  }
}

export class EnsPayToMismatch extends Data.TaggedError("EnsPayToMismatch")<{
  readonly name: string
  readonly field: "payTo" | "chain"
  readonly ensValue: string
  readonly challengeValue: string
}> {
  readonly code = "ens_payto_mismatch"
  get message(): string {
    return (
      `refusing to sign: ${this.name} says ${this.field} is ${this.ensValue}, but the 402 ` +
      `challenge asked for ${this.challengeValue}. The name is the authority over the ` +
      `payment destination. Nothing was signed.`
    )
  }
}

export interface EnsListing {
  readonly name: string
  readonly endpoint: string
  readonly payTo: string
  readonly chainCaip2: string
  /** Advisory only — the 402 challenge is what an authorization is signed against. */
  readonly priceAtomic?: bigint
}

export const ensRootFromEnv = (): string | undefined => {
  const root = process.env["ARCADE_ENS_ROOT"]
  return root === undefined || root.trim() === "" ? undefined : root.trim()
}

export const looksLikeEnsName = (s: string): boolean => s.includes(".") && s.endsWith(".eth")

export const sepoliaEnsReader = (): EnsReader => {
  const client = createPublicClient({
    chain: sepolia,
    transport: http(process.env["ARCADE_ENS_RPC"] ?? undefined)
  })
  const universalResolverAddress = (process.env["ARCADE_ENS_UNIVERSAL_RESOLVER"] ??
    loadEnsDeployments()[0]!.universalResolver) as `0x${string}`
  return {
    getEnsText: (a) => client.getEnsText({ ...a, universalResolverAddress })
  }
}

const text = (reader: EnsReader, name: string, key: string): Promise<string | null> =>
  reader.getEnsText({ name, key }).catch(() => null)

export const resolveEnsListing = (
  reader: EnsReader,
  rawName: string
): Effect.Effect<EnsListing, EnsNameExpired> =>
  Effect.gen(function* () {
    const name = normalize(rawName)
    const [endpoint, payTo, chain, price] = yield* Effect.promise(() =>
      Promise.all([
        text(reader, name, ENS_TEXT_KEYS.endpoint),
        text(reader, name, ENS_TEXT_KEYS.payTo),
        text(reader, name, ENS_TEXT_KEYS.chain),
        text(reader, name, ENS_TEXT_KEYS.priceAtomic)
      ])
    )
    // An expired name has no resolver, so every read comes back empty rather than wrong.
    // Treating "empty" as expired is the whole liveness contract.
    if (endpoint === null || endpoint === "") {
      return yield* new EnsNameExpired({ name, key: ENS_TEXT_KEYS.endpoint })
    }
    if (payTo === null || payTo === "") {
      return yield* new EnsNameExpired({ name, key: ENS_TEXT_KEYS.payTo })
    }
    return {
      name,
      endpoint,
      payTo,
      chainCaip2: chain ?? "",
      ...(price === null || price === "" ? {} : { priceAtomic: BigInt(price) })
    } satisfies EnsListing
  })

/**
 * The gate. Returns the refusal, or null to proceed — deliberately a value rather than a
 * throw, so the caller cannot forget to handle it and a test can assert the exact code.
 */
export const ensRefusal = (
  listing: EnsListing,
  req: { readonly payTo: string; readonly network: string }
): EnsPayToMismatch | null => {
  if (listing.payTo.toLowerCase() !== req.payTo.toLowerCase()) {
    return new EnsPayToMismatch({
      name: listing.name, field: "payTo", ensValue: listing.payTo, challengeValue: req.payTo
    })
  }
  if (listing.chainCaip2 !== "" && listing.chainCaip2 !== req.network) {
    return new EnsPayToMismatch({
      name: listing.name, field: "chain", ensValue: listing.chainCaip2, challengeValue: req.network
    })
  }
  return null
}

export const parseArcadeEndpoint = (
  endpoint: string
): { readonly hubUrl: string; readonly seller: string; readonly skillId: string } => {
  const url = new URL(endpoint)
  const m = /^\/x\/([^/]+)\/([^/]+)\/?$/.exec(url.pathname)
  if (m === null) {
    throw new Error(
      `arcade.endpoint on this name is ${endpoint}, which is not an ARCADE paid path ` +
        `(<origin>/x/<seller>/<skill>). The name's owner has to fix the record.`
    )
  }
  return { hubUrl: url.origin, seller: m[1]!, skillId: m[2]! }
}
```

```ts
import { ENS_TEXT_KEYS, arcadeSkillName, sellerLabelFor } from "@arcade/core"
import type { EnsReader } from "@arcade/buyer/ens-policy"

/**
 * The hub's read-only view of ENS liveness.
 *
 * A listing whose name no longer resolves is `expired`: the seller's runner stopped
 * renewing, so the subname lapsed. The hub does not decide this and cannot cause it — it
 * reads the consequence of a runner going quiet and hides the listing so nobody pays for
 * something nobody is serving.
 *
 * Three deliberate limits:
 *   1. With no `ARCADE_ENS_ROOT` this is completely inert. ENS is opt-in.
 *   2. A read that THROWS never expires anything. A Sepolia outage is not a seller's fault,
 *      and delisting the whole marketplace for someone else's RPC would be the worst
 *      possible reading of a network error. Only a successful read of an EMPTY record
 *      expires a listing.
 *   3. It is reversible on its own: a reconnecting runner renews, the name resolves again,
 *      and the next sweep unmarks it. No manual relist.
 */

export interface EnsWatchArgs {
  readonly root?: string | undefined
  readonly reader: EnsReader
  readonly log?: (line: string) => void
}

export interface EnsWatch {
  readonly sweep: (
    listings: ReadonlyArray<{ readonly id: string; readonly seller: string }>
  ) => Promise<void>
  readonly isExpired: (skillId: string) => boolean
  readonly nameFor: (l: { readonly id: string; readonly seller: string }) => string | undefined
  readonly start: (
    intervalMs: number,
    listings: () => Promise<ReadonlyArray<{ readonly id: string; readonly seller: string }>>
  ) => () => void
}

export const makeEnsWatch = (a: EnsWatchArgs): EnsWatch => {
  const log = a.log ?? ((line: string) => console.log(line))
  const expired = new Set<string>()

  const nameFor = (l: { readonly id: string; readonly seller: string }): string | undefined => {
    if (a.root === undefined || a.root === "") return undefined
    try {
      return arcadeSkillName({ root: a.root, sellerLabel: sellerLabelFor(l.seller), skillId: l.id })
    } catch {
      return undefined
    }
  }

  const sweep = async (
    listings: ReadonlyArray<{ readonly id: string; readonly seller: string }>
  ): Promise<void> => {
    for (const l of listings) {
      const name = nameFor(l)
      if (name === undefined) continue
      let value: string | null
      try {
        value = await a.reader.getEnsText({ name, key: ENS_TEXT_KEYS.endpoint })
      } catch (e) {
        log(`[ens] could not read ${name} (${String((e as Error)?.message ?? e)}) — leaving ${l.id} as it is`)
        continue
      }
      const gone = value === null || value === ""
      if (gone && !expired.has(l.id)) {
        expired.add(l.id)
        log(`[ens] ${name} no longer resolves — ${l.id} marked expired`)
      } else if (!gone && expired.delete(l.id)) {
        log(`[ens] ${name} resolves again — ${l.id} relisted`)
      }
    }
  }

  return {
    sweep,
    isExpired: (skillId) => expired.has(skillId),
    nameFor,
    start: (intervalMs, listings) => {
      const timer = setInterval(() => {
        void listings().then(sweep).catch(() => undefined)
      }, intervalMs)
      return () => clearInterval(timer)
    }
  }
}
```

```ts
      args: [node, ENS_TEXT_KEYS.priceAtomic, skill.priceAtomic], account: daemon
    })
    .then(() => false, () => true)
  check(nowRefused, "after one revocation tx, the daemon's next setText reverts")
}

const tampered402 = async (): Promise<void> => {
  console.log(`\nBEAT 2 — a tampered challenge, refused before signing`)
  const listing = await Effect.runPromise(resolveEnsListing(reader, skill.name))
  console.log(`  ${skill.name} → payTo ${listing.payTo} on ${listing.chainCaip2}`)

  check(
    ensRefusal(listing, { payTo: listing.payTo, network: listing.chainCaip2 }) === null,
    "an honest challenge passes"
  )
  const bad = ensRefusal(listing, {
    payTo: "0x000000000000000000000000000000000000dEaD", network: listing.chainCaip2
  })
  check(bad?.code === "ens_payto_mismatch", `a swapped payee is refused: ${bad?.code}`)
  console.log(`    ${bad?.message}`)
  const wrongChain = ensRefusal(listing, { payTo: listing.payTo, network: "eip155:1" })
  check(wrongChain?.code === "ens_payto_mismatch", "a challenge on the wrong chain is refused too")
}

const expiry = async (): Promise<void> => {
  console.log(`\nBEAT 3 — kill the runner; the name expires on its own`)
  console.log(`  stop the seller runner now (Ctrl-C in its terminal). TTL is ${state.ttlSeconds}s.`)
  const hub = process.env["ARCADE_HUB"] ?? "http://localhost:8787"
  const deadline = Date.now() + Number(process.env["ARCADE_ENS_DEMO_TIMEOUT_MS"] ?? 25 * 60_000)
  let nameGone = false
  let listingGone = false
  while (Date.now() < deadline && !(nameGone && listingGone)) {
    const value = await reader
      .getEnsText({ name: skill.name, key: ENS_TEXT_KEYS.endpoint })
      .catch(() => null)
    nameGone = value === null || value === ""
    const all = (await (await fetch(`${hub}/listings`)).json()) as ReadonlyArray<{ id: string }>
    listingGone = !all.some((l) => l.id === skill.skillId)
    console.log(
      `  ${new Date().toISOString()}  name ${nameGone ? "expired" : "live"} · ` +
        `marketplace ${listingGone ? "no longer lists it" : "still lists it"}`
    )
    if (nameGone && listingGone) break
    await new Promise((r) => setTimeout(r, 30_000))
  }
  check(nameGone, `${skill.name} stopped resolving once nothing renewed it`)
  check(listingGone, `the hub dropped ${skill.skillId} from /listings`)
}

if (beat === "price-lock" || beat === "all") await priceLock()
if (beat === "tampered-402" || beat === "all") await tampered402()
if (beat === "expiry" || beat === "all") await expiry()

console.log(failures.length === 0 ? "\nall beats held" : `\nFAILED: ${failures.join("; ")}`)
process.exit(failures.length === 0 ? 0 : 1)
```

**2. Ambiguities resolved.**
- *"renew on every heartbeat cycle"* would be a Sepolia transaction every 15 seconds. Resolved as: the loop **runs** on the heartbeat and **writes** at most once per `TTL / RENEW_FRACTION` (a quarter TTL) — four txs a day at 6h, one every ~3.75 min in the demo — with a failed renew deliberately not recorded so it retries on the next tick. `ensTtlSeconds` refuses a TTL under 60s for the same reason.
- *Which key renews.* The spec says "daemon key" without saying whether it is the seller's payout key. Resolved as a separate `ARCADE_ENS_DAEMON_KEY` on Sepolia, matching the repo's existing rule that the payout key never takes on second jobs (`daemon.ts:70-81`). It holds `ROLE_RENEW` plus one text key and nothing else.
- *Where the ENS state lives.* `~/.arcade/ens.json`, written by `ens-setup` and read by the runner — outside the repo, beside `~/.arcade/config.json`, and containing no key.
- *Hub expiry state.* Kept in `apps/hub/src/ens.ts`, not in `Store`, because it is a best-effort observation of another chain and because it keeps this plan off Plan A's transactional ledger. A read that *throws* never expires anything; only a successful read of an empty record does.

- *Address prediction.* The research notes the CREATE2 address can be predicted before deploy; the plan deploys the registry and resolver **before** `commit` instead, which needs no prediction and uses the mandatory 60-second commitment wait for something.
