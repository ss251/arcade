# Plan H — Web app (M8)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Grow `apps/web` from one chat page into the marketplace surface the whole economy is visible through — `/` catalogue, `/skill/$name` listing with a rendered receipt tree, `/seller` and `/buyer` dashboards, a `/publish` wizard that runs the real CLI in dry-run, and a chat that can hire by ENS name — served by three new read-only JSON endpoints on the hub.

**Architecture:** Every number on every page comes from the hub over JSON; the web service holds no key, no seller code and no job tokens (`docs/threat-model.md` T-PRIV-003 — the browser holds those, in `localStorage`). `apps/web/src/lib/hub.ts` stays the single server-side hub client (it reads `process.env["ARCADE_HUB"]`), pages reach it through `createServerFn` loaders, and every component is a pure function of props so `renderToStaticMarkup` can test it the way `apps/web/test/thread.test.tsx` already does. Three endpoints are added to `apps/hub/src/server.ts`, each with its aggregation written as a pure function in its own module so it is testable without `Bun.serve`.

**Tech Stack:** Bun 1.3, TanStack Start 1.168 + React 19, Effect 3.22 (Effect Schema, never zod), vitest 3 for `*.test.ts(x)`, `bun test` for `*.bun.test.ts`, `@arcade/core` for money formatting and explorer URLs, hand-authored inline SVG for the tree graph (no chart library).

### Design constraints (from `~/.claude/skills/design-sauce/SKILL.md`, which `CLAUDE.md` requires be loaded before any `apps/web` work)

- **Law 1 — hierarchy is spacing, not dividers.** Related things cluster at 8–12px, unrelated at 24–32px. Do not add a rule between sibling cards; widen the gap.
- **Law 2 — one accent, one meaning.** The tokens in `apps/web/src/styles.css:29-63` are already a closed budget: `--usdc` is USDC amounts, `--stamp` is *settled*, `--refuse` is *not settled*, links are underlined ink. A pay-test badge, an ENS-liveness dot and a tree node reuse `--stamp`/`--refuse` with **exactly** those meanings and invent no fourth hue.
- **Law 3 — the most important text is the brightest text.** The number or verdict is bright; labels, timestamps and addresses are demoted (`--slate`, smaller). Machine truth — tx hashes, skill ids, addresses, schemas — is `--mono`; prices, fees and latencies are `--sans` with `font-variant-numeric: tabular-nums`.
- **Law 4 — motion passes the frequency test.** Rows landing on a live feed appear **instantly**; no per-row fade or translate. The only motion in this plan is a ≤200ms `ease-out` opacity on the publish wizard's step change, and it is gated by `@media (prefers-reduced-motion: reduce)`.
- **Law 8 — scheme lives in the app.** Every new colour is a `light-dark()` token in `styles.css`, never a hex constant in a component.
- **Law 11 — verify on the rendered thing.** Task 14 screenshots every page in both schemes; a green test suite is not evidence a page looks right.

```ts
  readonly skillId: string
  readonly priceAtomic: string

  readonly settled: boolean
  readonly settleTx?: string
  readonly explorer: string | null
}

export interface PublicReceiptRow {
  readonly skillId: string
  readonly priceAtomic: string
  readonly sellerAtomic: string
  readonly feeAtomic: string
  readonly feeBps: number
  readonly price: string
  readonly sellerShare: string
  readonly fee: string
  readonly settled: boolean
  readonly reason: string
  readonly latencyMs: number
  readonly createdAtMs: number
  readonly settleTx?: string
  readonly explorer: string | null
  readonly hop: number
  readonly treeHash?: string

/**
 * The one public projection of a receipt.
 *
 * `jobId` is omitted because it is the handle a job token is minted against, and `buyer`
 * because a wallet address plus a skill id is a purchase history. Plan A gave receipts
 * `children`, and each child carries its own `jobId` — the same capability one level down,

  priceAtomic: r.priceAtomic.toString(),
  sellerAtomic: r.sellerAtomic.toString(),
  feeAtomic: r.feeAtomic.toString(),
  feeBps: r.feeBps,
  price: formatPrice(r.priceAtomic),
  sellerShare: formatPrice(r.sellerAtomic),
  fee: formatPrice(r.feeAtomic),

  reason: r.reason,
  latencyMs: r.latencyMs,
  createdAtMs: r.createdAtMs,

  explorer: r.settleTx === undefined ? null : explorerTxUrl(r.settleTx),
```

```ts
import { formatPrice, type Receipt } from "@arcade/core"
import type { ListingRecord, RunnerRecord } from "./store.ts"

/**
 * Per-seller economics, computed in ONE place.
 *
 * A marketplace that shows a seller revenue and not cost is showing them half a business,
 * and on a per-call product a single run can cost more than it earns. Three surfaces want
 * this arithmetic — the dashboard, the listing page and the demo script — so it is a pure
 * function over rows rather than a query, and it is tested without a server.
 *
 * Every figure is atomic `bigint` internally and an exact decimal string on the way out.
 */

/** A runner silent this long is not serving, whatever the listing row still says. */
const LIVENESS_MS = 30_000

/**
 * `sellerCostUsd` is a float the engine reported; the ledger is integral 6-dec. Rounding at
 * the boundary is deliberate: carrying the float further would put `0.30000000000000004`
 * into a subtraction whose result a human reads as money.
 */
export const usdToAtomic = (usd: number): bigint => BigInt(Math.round(usd * 1_000_000))

export interface SellerListingRow {
  readonly id: string
  readonly serviceName: string
  readonly price: string
  readonly live: boolean
  readonly delisted: boolean
  readonly payTestedAtMs?: number
  readonly payTestOk?: boolean
  readonly payTestTx?: string
  readonly ensName?: string
  readonly ensExpired?: boolean
  readonly agentId?: string
  readonly registrationTx?: string
  readonly agentVerified?: boolean
  readonly calls: number
  readonly settled: number
  readonly revenue: string
  readonly revenueAtomic: string
  readonly marginPerCall: string
  readonly marginPerCallAtomic: string
}

export interface SellerSummary {
  readonly seller: string
  readonly calls: number
  readonly settled: number
  readonly revenue: string
  readonly revenueAtomic: string
  readonly fees: string
  readonly feesAtomic: string
  readonly net: string
  readonly netAtomic: string
  readonly inferenceCost: string
  readonly inferenceCostAtomic: string
  readonly subSpend: string
  readonly subSpendAtomic: string
  readonly margin: string
  readonly marginAtomic: string
  readonly listings: ReadonlyArray<SellerListingRow>
}

/** `formatPrice` is unsigned; a loss has to read as one. */
const money = (atomic: bigint): string =>
  atomic < 0n ? `-${formatPrice(-atomic)}` : formatPrice(atomic)

const sum = (xs: ReadonlyArray<bigint>): bigint => xs.reduce((a, b) => a + b, 0n)

/** What this receipt paid OUT to children. Unsettled children cost nothing — that is D2. */
const subSpendOf = (r: Receipt): bigint =>
  sum((r.children ?? []).filter((c) => c.settled).map((c) => c.priceAtomic))

export const sellerSummary = (
  seller: string,
  listings: ReadonlyArray<ListingRecord>,
  receipts: ReadonlyArray<Receipt>,
  runners: ReadonlyArray<RunnerRecord>,
  nowMs: number
): SellerSummary => {
  const key = seller.toLowerCase()
  const mine = receipts.filter((r) => r.seller.toLowerCase() === key)
  const settled = mine.filter((r) => r.settled)

  const revenueAtomic = sum(settled.map((r) => r.priceAtomic))
  const feesAtomic = sum(settled.map((r) => r.feeAtomic))
  const netAtomic = sum(settled.map((r) => r.sellerAtomic))
  const costAtomic = sum(settled.map((r) => usdToAtomic(r.sellerCostUsd ?? 0)))
  const subAtomic = sum(settled.map(subSpendOf))
  const marginAtomic = netAtomic - costAtomic - subAtomic

  const liveSkills = new Set(
    runners
      .filter((rn) => rn.seller.toLowerCase() === key && nowMs - rn.lastSeenMs < LIVENESS_MS)
      .flatMap((rn) => rn.skillIds)
  )

  const rows = listings
    .filter((l) => l.seller.toLowerCase() === key)
    .map((l): SellerListingRow => {
      const rs = settled.filter((r) => r.skillId === l.listing.id)
      const rev = sum(rs.map((r) => r.priceAtomic))
      const perCall =
        rs.length === 0
          ? 0n
          : (sum(rs.map((r) => r.sellerAtomic)) -
              sum(rs.map((r) => usdToAtomic(r.sellerCostUsd ?? 0))) -
              sum(rs.map(subSpendOf))) / BigInt(rs.length)
      const rec = l as unknown as Record<string, never>
      // Plan C's PayTest, field-for-field: `atMs`, never `at`.
      const payTested = rec["payTested"] as
        | { atMs: number; jobId: string; ok: boolean; settleTx?: string }
        | undefined
      return {
        id: l.listing.id,
        serviceName: l.listing.serviceName,
        price: l.listing.price,
        live: liveSkills.has(l.listing.id),
        delisted: (rec["delisted"] as boolean | undefined) ?? false,
        ...(payTested === undefined
          ? {}
          : {
              payTestedAtMs: payTested.atMs,
              payTestOk: payTested.ok,
              ...(payTested.settleTx === undefined ? {} : { payTestTx: payTested.settleTx })
            }),
        ...(rec["ensName"] === undefined ? {} : { ensName: rec["ensName"] as string }),
        ...(rec["ensExpired"] === undefined ? {} : { ensExpired: rec["ensExpired"] as boolean }),
        // Plan D keeps identity on the record and the COUNTS off it (they are read per
        // request from the registries). The seller board therefore shows identity and
        // whether the hub verified it — never a count it would have to invent.
        ...(rec["agentId"] === undefined ? {} : { agentId: rec["agentId"] as string }),
        ...(rec["registrationTx"] === undefined
          ? {}
          : { registrationTx: rec["registrationTx"] as string }),
        ...(rec["agentVerified"] === undefined
          ? {}
          : { agentVerified: rec["agentVerified"] as boolean }),
        calls: mine.filter((r) => r.skillId === l.listing.id).length,
        settled: rs.length,
        revenue: money(rev),
        revenueAtomic: rev.toString(),
        marginPerCall: money(perCall),
        marginPerCallAtomic: perCall.toString()
      }
    })

  return {
    seller,
    calls: mine.length,
    settled: settled.length,
    revenue: money(revenueAtomic),
    revenueAtomic: revenueAtomic.toString(),
    fees: money(feesAtomic),
    feesAtomic: feesAtomic.toString(),
    net: money(netAtomic),
    netAtomic: netAtomic.toString(),
    inferenceCost: money(costAtomic),
    inferenceCostAtomic: costAtomic.toString(),
    subSpend: money(subAtomic),
    subSpendAtomic: subAtomic.toString(),
    margin: money(marginAtomic),
    marginAtomic: marginAtomic.toString(),
    listings: rows
  }
}
```

```ts
import { explorerTxUrl, formatPrice, type Receipt } from "@arcade/core"

/**
 * A receipt tree, shaped for drawing and stripped of anything that identifies a job.
 *
 * `jobId` is the handle a job token is minted against (`apps/hub/src/server.ts:303`), and
 * the child jobs in a tree belong to the HIRING SELLER's purchases, not the root buyer's.
 * So nodes are numbered by position — "0", "0.0", "0.0.1" — which is all a graph needs and
 * is not a handle to anything. The root's own id is echoed because the caller had to
 * present its token to get here.
 */

export interface TreeNode {
  readonly nodeId: string
  readonly parentNodeId: string | null
  readonly skillId: string
  readonly hop: number
  readonly priceAtomic: string
  readonly price: string
  readonly settled: boolean
  readonly reason: string
  readonly latencyMs: number
  readonly settleTx?: string
  readonly explorer: string | null
}

export interface TreeView {
  readonly rootJobId: string
  readonly treeHash?: string
  readonly ceiling?: string
  readonly committed?: string
  readonly nodes: ReadonlyArray<TreeNode>
}

export const buildTreeView = (
  rootJobId: string,
  receipts: ReadonlyArray<Receipt>
): TreeView | undefined => {
  const byJob = new Map(receipts.map((r) => [r.jobId, r]))
  const root = byJob.get(rootJobId)
  if (root === undefined) return undefined

  const nodes: Array<TreeNode> = []
  // Depth-first, and `seen` is the cycle guard. Plan A refuses cycles at the paid endpoint,
  // but a renderer that hangs when that guarantee slips is a worse outcome than one that
  // draws a truncated tree, so this does not assume the invariant it is displaying.
  const seen = new Set<string>()

  const walk = (jobId: string, nodeId: string, parentNodeId: string | null, hop: number): void => {
    if (seen.has(jobId)) return
    seen.add(jobId)
    const r = byJob.get(jobId)
    if (r === undefined) return
    nodes.push({
      nodeId,
      parentNodeId,
      skillId: r.skillId,
      hop: r.hop ?? hop,
      priceAtomic: r.priceAtomic.toString(),
      price: formatPrice(r.priceAtomic),
      settled: r.settled,
      reason: r.reason,
      latencyMs: r.latencyMs,
      ...(r.settleTx === undefined ? {} : { settleTx: r.settleTx }),
      explorer: r.settleTx === undefined ? null : explorerTxUrl(r.settleTx)
    })
    ;(r.children ?? []).forEach((c, i) => walk(c.jobId, `${nodeId}.${i}`, nodeId, hop + 1))
  }

  walk(rootJobId, "0", null, 0)

  return {
    rootJobId,
    ...(root.treeHash === undefined ? {} : { treeHash: root.treeHash }),
    ...(root.treeCeilingAtomic === undefined
      ? {}
      : { ceiling: formatPrice(root.treeCeilingAtomic) }),
    ...(root.treeCommittedAtomic === undefined
      ? {}
      : { committed: formatPrice(root.treeCommittedAtomic) }),
    nodes
  }
}
```

```ts
import { explorerAddressUrl, explorerTxUrl } from "@arcade/core"

/**
 * Display helpers. No money maths lives here — that is `formatPrice`'s job, on the server,
 * once. These only decide how much of a machine string fits on a line.
 */

/**
 * Elide the MIDDLE. A reader verifies a hash against another source by comparing both ends;
 * `0x6366ab…` alone is satisfied by any of 2^216 different hashes.
 */
export const shortHash = (s: string, head = 8, tail = 6): string =>
  s.length <= head + tail + 1 ? s : `${s.slice(0, head)}…${s.slice(-tail)}`

export const shortAddr = (a: string): string => shortHash(a, 8, 6)

export const ago = (ms: number, nowMs: number = Date.now()): string => {
  const s = Math.max(0, Math.round((nowMs - ms) / 1000))
  if (s < 30) return "just now"
  if (s < 3600) return `${Math.floor(s / 60)}m ago`
  if (s < 86_400) return `${Math.floor(s / 3600)}h ago`
  return `${Math.floor(s / 86_400)}d ago`
}

export const txLink = (tx: string): string => explorerTxUrl(tx)
export const addrLink = (address: string): string => explorerAddressUrl(address)
```

```ts
  let res: Response
```

```ts
// apps/web/src/lib/tree-layout.ts
import type { TreeNode, TreeView } from "./hub.ts"

/**
 * Where each job sits. Pure, so the picture is testable without a DOM.
 *
 * Layout is a left-to-right tidy tree: hop N is column N (the money flows rightwards, the
 * way the hire does), siblings stack downward, and a subtree reserves exactly as many rows
 * as it has leaves. Hand-rolled rather than pulled from a graph library because the shape is
 * a tree of at most `ARCADE_MAX_HOP` (3) levels and a layout engine would be more code than
 * this, plus a dependency in a bundle that ships to every visitor.
 */

export const NODE_W = 168
export const NODE_H = 52
export const COL_GAP = 72
export const ROW_GAP = 16

export interface PlacedNode extends TreeNode {
  readonly x: number
  readonly y: number
}

export interface Layout {
  readonly width: number
  readonly height: number
  readonly nodes: ReadonlyArray<PlacedNode>
  readonly edges: ReadonlyArray<{ readonly from: string; readonly to: string; readonly path: string }>
}

const ROW = NODE_H + ROW_GAP

export const layoutTree = (view: TreeView): Layout => {
  const kids = new Map<string | null, Array<TreeNode>>()
  for (const n of view.nodes) {
    const list = kids.get(n.parentNodeId) ?? []
    list.push(n)
    kids.set(n.parentNodeId, list)
  }

  const placed: Array<PlacedNode> = []
  let row = 0

  /** Post-order: a parent centres on the rows its own subtree consumed. */
  const place = (node: TreeNode, depth: number): number => {
    const children = kids.get(node.nodeId) ?? []
    if (children.length === 0) {
      const y = row * ROW
      row += 1
      placed.push({ ...node, x: depth * (NODE_W + COL_GAP), y })
      return y
    }
    const ys = children.map((c) => place(c, depth + 1))
    const y = (ys[0]! + ys[ys.length - 1]!) / 2
    placed.push({ ...node, x: depth * (NODE_W + COL_GAP), y })
    return y
  }

  const roots = kids.get(null) ?? []
  for (const r of roots) place(r, 0)

  const byId = new Map(placed.map((p) => [p.nodeId, p]))
  const edges = placed
    .filter((n) => n.parentNodeId !== null)
    .map((n) => {
      const p = byId.get(n.parentNodeId!)!
      const x1 = p.x + NODE_W
      const y1 = p.y + NODE_H / 2
      const x2 = n.x
      const y2 = n.y + NODE_H / 2
      const mid = (x1 + x2) / 2
      return { from: p.nodeId, to: n.nodeId, path: `M ${x1} ${y1} C ${mid} ${y1}, ${mid} ${y2}, ${x2} ${y2}` }
    })

  const depth = placed.length === 0 ? 0 : Math.max(...placed.map((p) => p.x)) / (NODE_W + COL_GAP)
  return {
    width: placed.length === 0 ? 0 : depth * (NODE_W + COL_GAP) + NODE_W,
    height: Math.max(row, 1) * ROW,
    nodes: placed,
    edges
  }
}
```

```tsx
// apps/web/src/components/tree-graph.tsx
import { shortHash } from "~/lib/format.ts"
import { NODE_H, NODE_W, layoutTree } from "~/lib/tree-layout.ts"
import type { TreeView } from "~/lib/hub.ts"

/**
 * The receipt tree, drawn.
 *
 * Inline SVG, no library. Law 2 holds: a settled hop is `--stamp`, a refused hop is
 * `--refuse`, the price is `--usdc`, and the graph introduces no fourth hue for "structure"
 * — edges are hairlines in `--line`.
 *
 * Law 4: nothing here animates. A tree appears once, fully formed, when a job finishes.
 *
 * A refused hop states its REASON in the box. A red rectangle tells a viewer that something
 * failed and not what, and the reason is the whole reason this product settles on success.
 *
 * The `<a>` wrapper is inside the SVG on purpose — an SVG-native link is what makes the box
 * itself the click target, so a viewer clicks the hop rather than hunting for a legend row.
 */
export const TreeGraph = ({ view }: { view: TreeView }) => {
  if (view.nodes.length === 0) return <p className="law">No hops — this job hired nobody.</p>
  const l = layoutTree(view)
  const settled = view.nodes.filter((n) => n.settled).length
  return (
    <figure className="tree">
      <svg
        viewBox={`0 0 ${l.width} ${l.height}`}
        width={l.width}
        height={l.height}
        role="img"
        aria-label={`Receipt tree: ${view.nodes.length} jobs, ${settled} settled`}
      >
        {l.edges.map((e) => (
          <path key={`${e.from}->${e.to}`} d={e.path} className="tree-edge" fill="none" />
        ))}
        {l.nodes.map((n) => {
          const box = (
            <g className={`node${n.settled ? " is-settled" : " is-refused"}`}>
              <rect x={n.x} y={n.y} width={NODE_W} height={NODE_H} rx={8} />
              <text x={n.x + 10} y={n.y + 20} className="node-skill">
                {n.skillId}
              </text>
              <text x={n.x + 10} y={n.y + 38} className="node-price">
                {n.price}
              </text>
              <text x={n.x + NODE_W - 10} y={n.y + 38} className="node-state" textAnchor="end">
                {n.settled ? "settled" : n.reason}
              </text>
            </g>
          )
          return n.explorer === null ? (
            <g key={n.nodeId}>{box}</g>
          ) : (
            <a key={n.nodeId} href={n.explorer} target="_blank" rel="noreferrer">
              {box}
            </a>
          )
        })}
      </svg>
      <figcaption>
        {view.treeHash === undefined ? (
          "not yet committed on chain"
        ) : (
          <>
            tree <span className="hashish">{shortHash(view.treeHash)}</span> committed on chain
          </>
        )}
        {view.committed === undefined ? null : (
          <>
            {" · "}
            {view.committed} of {view.ceiling} sub-budget spent
          </>
        )}
      </figcaption>
    </figure>
  )
}
```

```ts
// apps/web/src/lib/job-store.ts

/**
 * Job tokens live HERE, in the visitor's browser, and nowhere else.
 *
 * `docs/threat-model.md` T-PRIV-003: a job token is the capability to fetch a paid result.
 * If the web service held them it could re-fetch any buyer's purchase — the one component
 * that custodies no funds, no keys and no seller code would suddenly be able to read
 * everything anyone bought, invisibly, with nothing about the UI changing.
 *
 * The cost is stated rather than hidden: clearing storage or opening ARCADE on another
 * device loses the ability to re-fetch. The hub's receipt feed still proves the settlement
 * happened; the RESULT is the buyer's copy alone.
 *
 * Same shape as `lib/history.ts` — one JSON array under one key, every read defensive,
 * every write best-effort — because both are answering the same question about the same
 * storage and a second style here would just be a second thing to get wrong.
 */

export const KEY = "arcade.jobs.v1"

export interface StoredJob {
  readonly jobId: string
  readonly token: string
  readonly skillId: string
  /** Atomic 6-dec as a decimal string. Never a number, even in storage. */
  readonly priceAtomic: string
  readonly createdAtMs: number
  /** Plan F: the Gateway session this call was batched into, when there was one. */
  readonly sessionId?: string
}

/** Undefined during SSR and in a browser with storage disabled. Both are "no jobs". */
const storage = (): Storage | undefined => {
  try {
    return typeof localStorage === "undefined" ? undefined : localStorage
  } catch {
    return undefined
  }
}

const read = (): ReadonlyArray<StoredJob> => {
  const s = storage()
  if (s === undefined) return []
  try {
    const parsed: unknown = JSON.parse(s.getItem(KEY) ?? "[]")
    return Array.isArray(parsed) ? (parsed as ReadonlyArray<StoredJob>) : []
  } catch {
    return []
  }
}

const write = (jobs: ReadonlyArray<StoredJob>): void => {
  const s = storage()
  if (s === undefined) return
  try {
    s.setItem(KEY, JSON.stringify(jobs))
  } catch {
    // Quota, private mode, a disabled origin. Losing the ability to re-fetch is the
    // documented cost of the browser holding this; throwing here would lose the purchase.
  }
}

export const list = (): ReadonlyArray<StoredJob> =>
  [...read()].sort((a, b) => b.createdAtMs - a.createdAtMs)

export const get = (jobId: string): StoredJob | undefined =>
  read().find((j) => j.jobId === jobId)

export const remember = (job: StoredJob): void =>
  write([...read().filter((j) => j.jobId !== job.jobId), job])

export const forget = (jobId: string): void => write(read().filter((j) => j.jobId !== jobId))

export const forgetAll = (): void => write([])
```

```ts
// apps/web/src/lib/publish-preview.ts

/**
 * The wizard runs the REAL `arcade publish`, in dry-run, and shows its answer.
 *
 * A wizard that re-implemented the projection would be a second copy of the secrecy
 * boundary — and the copy a seller actually reads, while the CLI is the one that runs. When
 * they drifted, the page would keep promising a guarantee the transport had stopped keeping.
 * So this shells out and parses; the only logic here is which target strings are allowed.
 *
 * ## Why it refuses on a hosted deployment
 *
 * This spawns a process on the machine serving the page. On a laptop that machine is the
 * seller's and the whole point; on Railway it is ours, the "skill directory" would be a path
 * on our filesystem, and a public form that spawns a process against a user-supplied string
 * is a remote-execution surface no matter how carefully the argument is validated. So the
 * feature is keyed to `ARCADE_PUBLISH_LOCAL=1`, and `preflight.ts` refuses to boot if that
 * is set on a platform.
 */

export class PublishDisabled extends Error {
  readonly _tag = "PublishDisabled"
  constructor() {
    super(
      "publishing runs on your own machine. Run ARCADE locally " +
        "(`ARCADE_PUBLISH_LOCAL=1 bun run web`) — the hosted site cannot read your skill " +
        "directory, and that is the same boundary that keeps your code off our servers."
    )
  }
}

export class PublishFailed extends Error {
  readonly _tag = "PublishFailed"
}

export interface PublishPreview {
  readonly target: string
  readonly skillId: string
  readonly engine: { readonly adapter: string; readonly credential: string }
  readonly grants: ReadonlyArray<string>
  readonly advisory?: string
  readonly public: Record<string, unknown>
  readonly private: Record<string, unknown>
}

const PUBLIC_MARK = "PUBLISHED to the hub:"
const PRIVATE_MARK = "STAYS ON THIS MACHINE (never transmitted):"

/** The JSON object that starts at `from`, found by matching braces. */
const objectAt = (s: string, from: number): Record<string, unknown> => {
  const start = s.indexOf("{", from)
  if (start < 0) throw new PublishFailed("could not read the CLI output: no JSON object")
  let depth = 0
  for (let i = start; i < s.length; i++) {
    if (s[i] === "{") depth++
    else if (s[i] === "}" && --depth === 0) {
      return JSON.parse(s.slice(start, i + 1)) as Record<string, unknown>
    }
  }
  throw new PublishFailed("could not read the CLI output: unterminated JSON object")
}

export const parsePreview = (stdout: string): PublishPreview => {
  const trimmed = stdout.trim()
  if (trimmed.startsWith("{")) {
    try {
      return JSON.parse(trimmed) as PublishPreview
    } catch {
      throw new PublishFailed("could not read the CLI output: malformed JSON")
    }
  }
  const pubAt = stdout.indexOf(PUBLIC_MARK)
  const privAt = stdout.indexOf(PRIVATE_MARK)
  if (pubAt < 0 || privAt < 0) {
    throw new PublishFailed(`could not read the CLI output:\n${stdout.slice(0, 400)}`)
  }
  const engine = /^engine\s+(\S+)\s+\(([^)]+)\)/m.exec(stdout)
  const grants = /^grants\s+(.+)$/m.exec(stdout)
  const advisory = /^ADVISORY\n\n([\s\S]*?)\n\n/m.exec(stdout)
  const pub = objectAt(stdout, pubAt)
  return {
    target: "",
    skillId: String(pub["id"] ?? ""),
    engine: { adapter: engine?.[1] ?? "unknown", credential: engine?.[2] ?? "unknown" },
    grants:
      grants === undefined || grants[1]!.startsWith("no tools")
        ? []
        : grants[1]!.split(",").map((g) => g.trim()),
    ...(advisory === null ? {} : { advisory: advisory[1]! }),
    public: pub,
    private: objectAt(stdout, privAt)
  }
}

/**
 * `skills/x` (a relative or absolute path), `mcp://host:port`, or a path ending `.json`.
 * Anything else is refused — not sanitised. Argv is an ARRAY here, so a shell never sees the
 * string, but a validator that tries to clean input is a validator someone will outsmart.
 */
const TARGET = /^(mcp:\/\/[A-Za-z0-9._:/-]+|[A-Za-z0-9._/-]+(\.json)?)$/

export type Spawn = (argv: ReadonlyArray<string>) => Promise<string>

const bunSpawn: Spawn = async (argv) => {
  const proc = Bun.spawn(["bun", "run", "packages/runner/src/cli.ts", ...argv], {
    cwd: process.env["ARCADE_REPO_ROOT"] ?? process.cwd(),
    stdout: "pipe",
    stderr: "pipe"
  })
  const [out, err] = await Promise.all([
    new Response(proc.stdout).text(),
    new Response(proc.stderr).text()
  ])
  await proc.exited
  // The CLI writes advisories to stderr and the projection to stdout; both are the answer.
  return `${err}${out}`
}

export const preview = async (target: string, spawn: Spawn = bunSpawn): Promise<PublishPreview> => {
  if (process.env["ARCADE_PUBLISH_LOCAL"] !== "1") throw new PublishDisabled()
  if (!TARGET.test(target) || target.startsWith("-")) {
    throw new PublishFailed(
      `"${target}" is not a target. Give a skill directory, an mcp:// URL, or a path to an openapi.json.`
    )
  }
  return { ...parsePreview(await spawn(["publish", target, "--json"])), target }
}
```

```ts
  readonly skillId?: string
  readonly name?: string
  readonly maxAmountUsd: string
  readonly toolCallId: string
}): Promise<SigningRequest> => {
  const approvedAtomic = parsePrice(approved.maxAmountUsd)

  // A name is resolved FIRST and to a skill id, so everything below this line is the exact
  // path a purchase by id already takes. The name adds one check and changes nothing else —
  // which is what keeps third-party x402 clients working on root calls.
  const resolved =
    approved.name === undefined ? undefined : await hub.resolveName(approved.name)
  if (resolved !== undefined && resolved.expired) throw new EnsNameExpired(approved.name!)
  const skillId = resolved?.skillId ?? approved.skillId
  if (skillId === undefined) throw new Error("one of skillId or name is required")

  const quote = await hub.quote(skillId)
  const quotedAtomic = BigInt(quote.amountAtomic)

  if (resolved !== undefined && resolved.payTo.toLowerCase() !== quote.payTo.toLowerCase()) {
    throw new EnsPayToMismatch(resolved.name, resolved.payTo, quote.payTo)
  }
  if (quotedAtomic > approvedAtomic) {
    throw new PriceMovedAboveApproval(quotedAtomic, approvedAtomic)
  }

  return {
    skillId: quote.skillId,
    ...(resolved === undefined ? {} : { name: resolved.name }),
    resource: quote.resource,
    payTo: quote.payTo,
    asset: quote.asset,
    network: quote.network,
    amountAtomic: quote.amountAtomic,
    price: formatPrice(quotedAtomic),
    toolCallId: approved.toolCallId
  }
}
```
