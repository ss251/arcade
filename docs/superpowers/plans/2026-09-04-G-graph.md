# Plan G — The Graph (M7): ARCADE ledger subgraph on Arc + the cost-of-goods skill on Base

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make The Graph load-bearing in two directions at once — ARCADE's own settlement ledger (FeeSplitterV2 `Settled`/`SettledTree` plus the three Arc ERC-8004 registries) becomes a queryable subgraph on `arc-testnet` that the hub reads for listing evidence and dashboards, and a paid ARCADE skill buys its facts from The Graph's x402 gateway on Base so a buyer's Arc settlement is backed by a real cost of goods on another chain.

**Architecture:** Two independent halves that never block each other. Half one is a new top-level `subgraph/` directory (graph-cli 0.98.1, AssemblyScript mappings, Subgraph Studio) whose manifest is generated from a template plus a checked-in splitter list, with a `templates` data source so splitters announced after deploy are picked up from ERC-8004 `MetadataSet` events; `apps/hub/src/graph.ts` is a fail-soft Effect service reading the Studio query URL, and SQLite stays authoritative for every job-state answer. Half two is `skills/counterparty-graph/`, a `script`-engine listing that pays `https://gateway.thegraph.com/api/x402/subgraphs/id/…` in USDC on Base with a keychain-held payer key and synthesises a verdict — never raw GraphQL — so any failure produces no schema-valid output and Arc never settles.

**Tech Stack:** `@graphprotocol/graph-cli@0.98.1`, `@graphprotocol/graph-ts@0.38.2`, `matchstick-as@0.6.0` (AssemblyScript, subgraph only); `@graphprotocol/client-x402@1.0.0` + `viem@2.56.3` (skill); Bun 1.3, TypeScript, Effect 3.22 (Effect Schema, `Data.TaggedError`, `Context.Tag`/`Layer`), vitest 3, `bun test` for `*.bun.test.ts`.

### Task 3: ABIs, the manifest template, and how splitters get announced

This is the design decision the spec leaves open. graph-node can only index a contract it
was told about, and a `templates` data source can only be instantiated **from inside a
handler**. ARCADE has no registry contract emitting "seller X announced splitter Y" — the
announcement happens in a signed WebSocket `Hello` to the hub (`apps/hub/src/server.ts:495-506`,
stored as `ListingRecord.feeSplitter`, `apps/hub/src/store.ts:26-32`), which is off chain and
therefore invisible to a subgraph.

Three options were on the table:

1. **Ship an `ArcadeRegistry.sol` emitting `SplitterAnnounced(address,string)`.** Cleanest —
   one handler, complete coverage, no coupling. Costs a fourth contract, a per-seller
   on-chain transaction, and a Foundry suite, in a week that already ships FeeSplitterV2.
   Rejected on budget, not on merit.
2. **Static data sources only**, generated from a checked-in list. Gives *full history* from
   each splitter's creation block, needs zero new on-chain surface — and requires a rebuild
   and redeploy every time a seller lists. Fine for a demo, wrong for a marketplace.
3. **A `templates` data source instantiated from an event we already emit.** M4 registers
   every listing in Arc's ERC-8004 IdentityRegistry, and ERC-8004's `setMetadata` emits
   `MetadataSet(uint256 indexed agentId, string indexed indexedMetadataKey, string metadataKey, bytes metadataValue)`
   for any key other than the reserved `agentWallet`. So the seller's own identity
   registration *is* the announcement channel, for free.

**This plan does 2 and 3 together**, and the reason is that their failure modes are exactly
complementary. A dynamic data source is indexed only from the block in which it was created,
so a splitter announced by `MetadataSet` at block N contributes **nothing before N** — its
earlier settlements are invisible. A static data source has the opposite shape: complete
from `startBlock`, but frozen at deploy time. Running both means known sellers get full
history and sellers who appear after the deploy get covered with no redeploy, at the cost of
having to dedupe (`Splitter` is keyed by address and its `source` field records which path
found it first). The residual gap — a seller who lists *and* settles after the deploy but
never registers an ERC-8004 identity — is closed by re-running `scripts/graph-splitters.ts`

```ts
/**
 * Renders subgraph.yaml from the template plus splitters.json.
 *
 * The generated manifest is NOT committed: it is a function of two files that are, and a
 * checked-in copy is a third place for the splitter list to be wrong. `bun run manifest`
 * before every codegen/build/deploy — the package scripts chain it for you.
 */
import { readFileSync, writeFileSync } from "node:fs"
import { dirname, join } from "node:path"
import { fileURLToPath } from "node:url"

const here = dirname(fileURLToPath(import.meta.url))
const template = readFileSync(join(here, "subgraph.template.yaml"), "utf8")
const list = JSON.parse(readFileSync(join(here, "splitters.json"), "utf8")) as {
  erc8004StartBlock: number
  splitters: Array<{ address: string; listingId: string; startBlock: number; note?: string }>
}

const seen = new Set<string>()
const sources = list.splitters
  .filter((s) => {
    const k = s.address.toLowerCase()
    if (seen.has(k)) return false
    seen.add(k)
    return true
  })
  .map(
    (s, i) => `  - kind: ethereum
    name: FeeSplitterStatic${i}
    network: arc-testnet
    source:
      address: "${s.address}"
      abi: FeeSplitterV2
      startBlock: ${s.startBlock}
    mapping:
      kind: ethereum/events
      apiVersion: 0.0.9
      language: wasm/assemblyscript
      file: ./src/fee-splitter.ts
      entities: [Settlement, Tree, Splitter, Marketplace]
      abis:
        - name: FeeSplitterV2
          file: ./abis/FeeSplitterV2.json
      eventHandlers:
        - event: Settled(indexed address,uint256,uint256,uint256,indexed bytes32)
          handler: handleSettled
        - event: SettledTree(indexed address,uint256,uint256,uint256,indexed bytes32,indexed bytes32,uint32,uint256)
          handler: handleSettledTree`
  )
  .join("\n")

if (sources === "") throw new Error("splitters.json is empty; a manifest with no data sources will not deploy")

writeFileSync(
  join(here, "subgraph.yaml"),
  template
    .replace("{{SPLITTER_SOURCES}}", sources)
    .replace(/\{\{ERC8004_START_BLOCK\}\}/g, String(list.erc8004StartBlock)),
  "utf8"
)
console.log(`subgraph.yaml: ${seen.size} static splitter source(s) + 3 registries + 1 template`)
```

```ts
import { BigInt, Bytes } from "@graphprotocol/graph-ts"
import { Marketplace, Splitter } from "../generated/schema"

/** Arc testnet. Baked in because the manifest is per-network; a mainnet deploy re-renders it. */
export const ARC_CHAIN_ID = BigInt.fromI32(5042002)
export const MARKETPLACE_ID = "arcade"

export function marketplace(): Marketplace {
  let m = Marketplace.load(MARKETPLACE_ID)
  if (m == null) {
    m = new Marketplace(MARKETPLACE_ID)
    m.settlementCount = BigInt.zero()
    m.treeCount = BigInt.zero()
    m.settledVolumeAtomic = BigInt.zero()
    m.feeAtomic = BigInt.zero()
    m.childTotalAtomic = BigInt.zero()
    m.agentCount = BigInt.zero()
    m.feedbackCount = BigInt.zero()
    m.validationRequestCount = BigInt.zero()
    m.validationPassCount = BigInt.zero()
    m.splitterCount = BigInt.zero()
    m.updatedAt = BigInt.zero()
  }
  return m as Marketplace
}

/**
 * Get-or-create a Splitter. `source` records which channel found it FIRST and is never
 * overwritten: a splitter discovered statically already has full history, and relabelling it
 * "metadata" when the seller later registers an identity would lose that fact.
 */
export function splitterFor(address: Bytes, source: string, block: BigInt): Splitter {
  let s = Splitter.load(address)
  if (s == null) {
    s = new Splitter(address)
    s.source = source
    s.firstSeenBlock = block
    s.settlementCount = BigInt.zero()
    s.settledVolumeAtomic = BigInt.zero()
    s.save()
    const m = marketplace()
    m.splitterCount = m.splitterCount.plus(BigInt.fromI32(1))
    m.updatedAt = block
    m.save()
  }
  return s as Splitter
}

/** Agent0's convention, so a client that speaks Agent0 can read this subgraph unchanged. */
export function agentEntityId(chainId: BigInt, agentId: BigInt): string {
  return chainId.toString() + ":" + agentId.toString()
}
```

```ts
import { BigInt } from "@graphprotocol/graph-ts"
import { Settled, SettledTree } from "../generated/templates/FeeSplitterV2/FeeSplitterV2"
import { Settlement, Tree } from "../generated/schema"
import { marketplace, splitterFor } from "./ids"

/**
 * `settle` and `settleWithTree` are disjoint: FeeSplitterV2.settle emits Settled and
 * settleWithTree emits SettledTree, never both, so counting each once is correct and no
 * de-duplication is needed. Every amount here is 6-decimal atomic USDC.
 */
function record(
  event: Settled,
  buyerBytes: BigInt | null
): Settlement {
  const splitter = splitterFor(event.address, "static", event.block.number)
  const s = new Settlement(event.transaction.hash.concatI32(event.logIndex.toI32()))
  s.splitter = splitter.id

  s.totalAtomic = event.params.total

  s.nonce = event.params.nonce
  s.blockNumber = event.block.number
  s.timestamp = event.block.timestamp
  s.txHash = event.transaction.hash

  splitter.settlementCount = splitter.settlementCount.plus(BigInt.fromI32(1))
  splitter.settledVolumeAtomic = splitter.settledVolumeAtomic.plus(event.params.total)
  splitter.save()

  m.updatedAt = event.block.timestamp
  m.save()
  return s
}

export function handleSettled(event: Settled): void {
  const s = record(event, null)
  s.save()
}

export function handleSettledTree(event: SettledTree): void {

  // event is reinterpreted rather than duplicated.

  t.root = s.id
  t.childCount = event.params.childCount.toI32()
  t.childTotalAtomic = event.params.childTotalAtomic
  t.blockNumber = event.block.number
  t.timestamp = event.block.timestamp
  t.txHash = event.transaction.hash
  t.save()

  s.tree = t.id
  s.save()

  const m = marketplace()
  m.treeCount = m.treeCount.plus(BigInt.fromI32(1))
  m.childTotalAtomic = m.childTotalAtomic.plus(event.params.childTotalAtomic)
  m.updatedAt = event.block.timestamp
  m.save()
}
```

```ts
import { Address, BigInt, Bytes } from "@graphprotocol/graph-ts"
import { MetadataSet, Registered, URIUpdated } from "../generated/IdentityRegistry/IdentityRegistry"
import { Agent, Listing, Splitter } from "../generated/schema"
import { FeeSplitterV2 } from "../generated/templates"
import { ARC_CHAIN_ID, agentEntityId, marketplace, splitterFor } from "./ids"

/**
 * ARCADE announces a listing's fee splitter through ERC-8004 metadata, because ERC-8004 is
 * the only on-chain registry both halves of the marketplace already write to. Values are
 * UTF-8 TEXT, not ABI-encoded: the same bytes have to be legible in a block explorer and to
 * a client that never loads an ABI.
 */
const KEY_LISTING_ID = "arcade.listingId"
const KEY_FEE_SPLITTER = "arcade.feeSplitter"
const KEY_PRICE_ATOMIC = "arcade.priceAtomic"
const KEY_ENDPOINT = "arcade.endpoint"
const KEY_AGENT_WALLET = "agentWallet"

function agentFor(agentId: BigInt, registry: Bytes, block: BigInt, ts: BigInt): Agent {
  const id = agentEntityId(ARC_CHAIN_ID, agentId)
  let a = Agent.load(id)
  if (a == null) {
    a = new Agent(id)
    a.chainId = ARC_CHAIN_ID
    a.agentId = agentId
    a.registry = registry
    a.owner = Bytes.empty()
    a.createdAt = ts
    a.feedbackCount = BigInt.zero()
    a.validationRequestCount = BigInt.zero()
    a.validationPassCount = BigInt.zero()
    const m = marketplace()
    m.agentCount = m.agentCount.plus(BigInt.fromI32(1))
    m.updatedAt = ts
    m.save()
  }
  a.updatedAt = ts
  return a as Agent
}

export function handleRegistered(event: Registered): void {
  const a = agentFor(event.params.agentId, event.address, event.block.number, event.block.timestamp)
  a.owner = event.params.owner
  a.agentURI = event.params.agentURI
  a.save()
}

export function handleURIUpdated(event: URIUpdated): void {
  const a = agentFor(event.params.agentId, event.address, event.block.number, event.block.timestamp)
  a.agentURI = event.params.newURI
  a.save()
}

export function handleMetadataSet(event: MetadataSet): void {
  const a = agentFor(event.params.agentId, event.address, event.block.number, event.block.timestamp)
  const key = event.params.metadataKey
  const value = event.params.metadataValue.toString()

  if (key == KEY_AGENT_WALLET) {
    a.agentWallet = Bytes.fromHexString(value) as Bytes
    a.save()
    return
  }
  if (key != KEY_LISTING_ID && key != KEY_FEE_SPLITTER && key != KEY_PRICE_ATOMIC && key != KEY_ENDPOINT) {
    // Not ours. A registry shared with every other agent on Arc will carry keys this
    // subgraph has no opinion about, and guessing at them is how a ledger starts lying.
    a.save()
    return
  }

  // The Listing is keyed by the ARCADE listing id, which may arrive in any order relative to
  // the other keys. Until arcade.listingId is seen, the agent's own id stands in, and the
  // seller's registration writes listingId first (arcade identity register, Plan D).
  let listingId = a.listing
  if (key == KEY_LISTING_ID) listingId = value
  if (listingId === null) { a.save(); return }

  let l = Listing.load(listingId as string)
  if (l == null) {
    l = new Listing(listingId as string)
    l.agent = a.id
  }
  if (key == KEY_PRICE_ATOMIC) l.priceAtomic = BigInt.fromString(value)
  if (key == KEY_ENDPOINT) l.endpoint = value
  if (key == KEY_FEE_SPLITTER) {
    const addr = Address.fromString(value)
    const known = Splitter.load(addr)
    const s = splitterFor(addr, "metadata", event.block.number)
    s.listing = l.id
    s.save()
    if (known == null) {
      // A dynamic data source is indexed only from the block it is created in, so this
      // splitter's settlements BEFORE this block are invisible until it also appears in
      // splitters.json. That is the documented trade in subgraph/README.md.
      FeeSplitterV2.create(addr)
    }
    l.feeSplitter = s.id
  }
  l.updatedAt = event.block.timestamp
  l.save()

  a.listing = l.id
  a.save()
}
```

```ts
  if (v == null) return // a response to a request from before this subgraph's start block

  v.response = event.params.response
  v.responseURI = event.params.responseURI
```

```ts
/**
 * Regenerates subgraph/splitters.json from a live hub's /listings.
 *
 * The hub is the only place that knows which splitter a seller announced — the announcement
 * is a signed WebSocket Hello, not a transaction (apps/hub/src/server.ts:495-506). This
 * script is the bridge: it turns that off-chain fact into the static half of the manifest,
 * so those splitters are indexed from their creation block rather than from whenever an
 * ERC-8004 metadata write happened to announce them.
 *
 *   bun run scripts/graph-splitters.ts --hub https://arcade-hub-production.up.railway.app
 */
import { readFileSync, writeFileSync } from "node:fs"

const arg = (name: string, fallback: string): string => {
  const i = process.argv.indexOf(`--${name}`)
  return i === -1 ? fallback : (process.argv[i + 1] ?? fallback)
}

const hub = arg("hub", "https://arcade-hub-production.up.railway.app")
const explorer = arg("explorer", "https://testnet.arcscan.app")
const out = arg("out", "subgraph/splitters.json")

const creationBlock = async (address: string): Promise<number> => {
  // The explorer's etherscan-compatible API is named by The Graph's own networks registry
  // for arc-testnet, so this is the same source graph-node's operators use.
  const r = await fetch(`${explorer}/api?module=contract&action=getcontractcreation&contractaddresses=${address}`)
  if (!r.ok) return 0
  const j = (await r.json()) as { result?: Array<{ blockNumber?: string }> }
  const b = j.result?.[0]?.blockNumber
  return b === undefined ? 0 : Number(b)
}

const main = async (): Promise<void> => {
  const r = await fetch(`${hub}/listings`)
  if (!r.ok) throw new Error(`${hub}/listings responded ${r.status}`)
  const listings = (await r.json()) as Array<{ id: string; feeSplitter?: string }>

  const existing = JSON.parse(readFileSync(out, "utf8")) as {
    erc8004StartBlock: number
    splitters: Array<{ address: string; listingId: string; startBlock: number; note?: string }>
  }
  const byAddress = new Map(existing.splitters.map((s) => [s.address.toLowerCase(), s]))

  for (const l of listings) {
    if (l.feeSplitter === undefined) continue
    const key = l.feeSplitter.toLowerCase()
    if (byAddress.has(key)) continue
    const startBlock = await creationBlock(l.feeSplitter)
    byAddress.set(key, { address: key, listingId: l.id, startBlock })
    console.log(`+ ${l.id} → ${key} @ block ${startBlock}`)
  }

  const next = { ...existing, splitters: [...byAddress.values()].sort((a, b) => (a.address < b.address ? -1 : 1)) }
  writeFileSync(out, `${JSON.stringify(next, null, 2)}\n`, "utf8")
  console.log(`${out}: ${next.splitters.length} splitter(s)`)
}

main().catch((e) => {
  console.error("FATAL", e instanceof Error ? e.message : e)
  process.exit(1)
})
```

or returning indexing errors, the correct behavior is that a number disappears from a page,
never that a job changes outcome. `Effect.Effect<X | null>` (no error type) makes that
un-routable-around at the type level rather than by convention.

```ts
import { Context, Effect, Layer } from "effect"

/**
 * The ARCADE ledger subgraph, read from Subgraph Studio.
 *
 * SQLITE STAYS AUTHORITATIVE. Everything here is evidence about the chain, not state: job
 * status, receipts, budgets and settlement decisions are read from `Store` and never from
 * this service. The subgraph answers questions the hub cannot answer cheaply from its own
 * rows — how many settlements this splitter has ever taken, whether a tree hash is actually
 * on chain, what the registries say about a listing's agent — and it answers them for
 * PAGES, not for PAYMENTS.
 *
 * Consequently every method's error channel is `never` and every failure becomes `null`.
 * If Studio is down, a number disappears from a page. Nothing else changes. That is not
 * defensive coding, it is the spec: "subgraph writes are best-effort side effects that
 * never change settlement outcomes."
 */

export interface GraphStats {
  readonly settlementCount: number
  readonly treeCount: number
  readonly settledVolumeAtomic: bigint
  readonly feeAtomic: bigint
  readonly childTotalAtomic: bigint
  readonly agentCount: number
  readonly feedbackCount: number
  readonly validationPassCount: number
  /** The block the subgraph has indexed to. Render it — a stale ledger should look stale. */
  readonly indexedBlock: number
}

export interface AgentEvidence {
  readonly agentId: string
  readonly agentUrl: string | null
  readonly settlementCount: number
  readonly settledVolumeAtomic: bigint
  readonly feedbackCount: number
  readonly validationPassCount: number
}

export interface TreeView {
  readonly treeHash: string
  readonly childCount: number
  readonly childTotalAtomic: bigint
  readonly rootTxHash: string
  readonly totalAtomic: bigint
  readonly timestampMs: number
}

export interface Graph {
  readonly stats: () => Effect.Effect<GraphStats | null>
  readonly evidenceFor: (listingId: string) => Effect.Effect<AgentEvidence | null>
  readonly treeFor: (treeHash: string) => Effect.Effect<TreeView | null>
}

export class GraphTag extends Context.Tag("@arcade/hub/Graph")<GraphTag, Graph>() {}

const STATS_QUERY = `query Stats {
  _meta { block { number } hasIndexingErrors }
  marketplace(id: "arcade") {
    settlementCount treeCount settledVolumeAtomic feeAtomic childTotalAtomic
    agentCount feedbackCount validationPassCount
  }
}`

const EVIDENCE_QUERY = `query Evidence($id: ID!) {
  listing(id: $id) {
    id
    agent { id agentURI feedbackCount validationPassCount }
    feeSplitter { settlementCount settledVolumeAtomic }
  }
}`

const TREE_QUERY = `query TreeByHash($id: Bytes!) {
  tree(id: $id) {
    id childCount childTotalAtomic timestamp
    root { txHash totalAtomic }
  }
}`

const num = (v: unknown): number => (typeof v === "string" ? Number(v) : typeof v === "number" ? v : 0)
const big = (v: unknown): bigint => {
  try {
    return typeof v === "string" || typeof v === "number" ? BigInt(v) : 0n
  } catch {
    return 0n
  }
}

interface Cached {
  readonly atMs: number
  readonly value: unknown
}

export const makeGraph = (opts: {
  readonly url: string
  readonly apiKey?: string | undefined
  readonly ttlMs?: number | undefined
  readonly fetchImpl?: typeof fetch | undefined
}): Graph => {
  const ttlMs = opts.ttlMs ?? 30_000
  const doFetch = opts.fetchImpl ?? fetch
  const cache = new Map<string, Cached>()

  const post = async (query: string, variables: Record<string, unknown>): Promise<Record<string, unknown> | null> => {
    const headers: Record<string, string> = { "content-type": "application/json" }
    if (opts.apiKey !== undefined && opts.apiKey !== "") headers["Authorization"] = `Bearer ${opts.apiKey}`
    const res = await doFetch(opts.url, {
      method: "POST",
      headers,
      body: JSON.stringify({ query, variables }),
      signal: AbortSignal.timeout(5_000)
    })
    if (!res.ok) return null
    const body = (await res.json()) as { data?: Record<string, unknown>; errors?: Array<unknown> }
    if (body.errors !== undefined && body.errors.length > 0) return null
    return body.data ?? null
  }

  /** Cache + swallow. The key is the query name plus its variables. */
  const query = <A>(
    key: string,
    document: string,
    variables: Record<string, unknown>,
    decode: (data: Record<string, unknown>) => A | null
  ): Effect.Effect<A | null> =>
    Effect.promise(async () => {
      const hit = cache.get(key)
      if (hit !== undefined && Date.now() - hit.atMs < ttlMs) return hit.value as A | null
      let value: A | null = null
      try {
        const data = await post(document, variables)
        value = data === null ? null : decode(data)
      } catch {
        value = null
      }
      cache.set(key, { atMs: Date.now(), value })
      return value
    })

  return {
    stats: () =>
      query("stats", STATS_QUERY, {}, (data) => {
        const meta = data["_meta"] as { block?: { number?: number }; hasIndexingErrors?: boolean } | null
        const m = data["marketplace"] as Record<string, unknown> | null
        // A subgraph that failed mid-chain keeps answering, with a frozen block. Reporting
        // its numbers as current is the one way this service can actively mislead.
        if (meta == null || meta.hasIndexingErrors === true || m == null) return null
        return {
          settlementCount: num(m["settlementCount"]),
          treeCount: num(m["treeCount"]),
          settledVolumeAtomic: big(m["settledVolumeAtomic"]),
          feeAtomic: big(m["feeAtomic"]),
          childTotalAtomic: big(m["childTotalAtomic"]),
          agentCount: num(m["agentCount"]),
          feedbackCount: num(m["feedbackCount"]),
          validationPassCount: num(m["validationPassCount"]),
          indexedBlock: num(meta.block?.number)
        }
      }),

    evidenceFor: (listingId) =>
      query(`evidence:${listingId}`, EVIDENCE_QUERY, { id: listingId }, (data) => {
        const l = data["listing"] as Record<string, unknown> | null
        if (l == null) return null
        const agent = l["agent"] as Record<string, unknown> | null
        const splitter = l["feeSplitter"] as Record<string, unknown> | null
        if (agent == null) return null
        return {
          agentId: String(agent["id"]),
          agentUrl: typeof agent["agentURI"] === "string" ? (agent["agentURI"] as string) : null,
          settlementCount: num(splitter?.["settlementCount"]),
          settledVolumeAtomic: big(splitter?.["settledVolumeAtomic"]),
          feedbackCount: num(agent["feedbackCount"]),
          validationPassCount: num(agent["validationPassCount"])
        }
      }),

    treeFor: (treeHash) => {
      const id = treeHash.toLowerCase()
      return query(`tree:${id}`, TREE_QUERY, { id }, (data) => {
        const t = data["tree"] as Record<string, unknown> | null
        if (t == null) return null
        const root = t["root"] as Record<string, unknown> | null
        return {
          treeHash: String(t["id"]),
          childCount: num(t["childCount"]),
          childTotalAtomic: big(t["childTotalAtomic"]),
          rootTxHash: root == null ? "" : String(root["txHash"]),
          totalAtomic: big(root?.["totalAtomic"]),
          timestampMs: num(t["timestamp"]) * 1000
        }
      })
    }
  }
}

/** Every answer is "I don't know". Used when ARCADE_GRAPH_URL is unset, and as the fallback. */
export const graphOff: Graph = {
  stats: () => Effect.succeed(null),
  evidenceFor: () => Effect.succeed(null),
  treeFor: () => Effect.succeed(null)
}

export const GraphOff: Layer.Layer<GraphTag> = Layer.succeed(GraphTag, graphOff)

export const GraphFromEnv = (): Layer.Layer<GraphTag> => {
  const url = process.env["ARCADE_GRAPH_URL"]
  if (url === undefined || url === "") return GraphOff
  const ttl = process.env["ARCADE_GRAPH_TTL_MS"]
  return Layer.succeed(
    GraphTag,
    makeGraph({
      url,
      apiKey: process.env["ARCADE_GRAPH_KEY"],
      ttlMs: ttl === undefined ? undefined : Number(ttl)
    })
  )
}
```

```ts
/**
 * Two GraphQL results in, one decision out.
 *
 * This file is the whole reason the skill is not a proxy. A buyer who wanted rows could buy
 * them from The Graph directly for a cent; what they cannot get from a gateway is the join
 * across identity, validation and settlement-backed feedback, the rules that turn it into
 * allow / manual-review / refuse, and the CONTRADICTIONS that justify the answer. Pure and
 * total: no network, no clock, no randomness, so every branch is testable for free.
 */

export interface Identity {
  readonly agentId: string
  readonly chainId: number
  readonly owner: string
  readonly agentWallet: string | null
  readonly name: string | null
  readonly active: boolean | null
  readonly x402Support: boolean | null
  readonly ens: string | null
  readonly supportedTrusts: ReadonlyArray<string>
  readonly validationsPassed: number
  readonly validationsFailed: number
}

export interface Source {
  readonly name: string
  readonly endpoint: string
  readonly subgraphId: string
  readonly block: number
  readonly chain: string
  readonly costAtomic: string
  readonly paymentTx?: string | null
}

export interface Assessment {
  readonly address: string
  readonly verdict: "allow" | "manual-review" | "refuse"
  readonly identities: ReadonlyArray<Identity>
  readonly attesterSettledCount: number
  readonly contradictions: ReadonlyArray<string>
  readonly sources: ReadonlyArray<Source>
}

/** Stable codes, so a buyer agent can branch on them without parsing prose. */
export const CONTRADICTION_CODES = [
  "no-erc8004-identity",
  "validation-failed",
  "registration-inactive",
  "x402-unsupported",
  "wallet-differs-from-owner",
  "feedback-revoked",
  "self-attested",
  "unattested-no-proof-of-payment"
] as const

/** A failed validation or a missing identity is disqualifying; everything else is a flag. */
const REFUSING = new Set<string>(["no-erc8004-identity", "validation-failed"])

const asArray = (v: unknown): ReadonlyArray<Record<string, unknown>> =>
  Array.isArray(v) ? (v.filter((x) => x !== null && typeof x === "object") as Array<Record<string, unknown>>) : []

const str = (v: unknown): string | null => (typeof v === "string" && v !== "" ? v : null)
const lower = (v: unknown): string | null => (typeof v === "string" ? v.toLowerCase() : null)
const boolOrNull = (v: unknown): boolean | null => (typeof v === "boolean" ? v : null)

const toIdentity = (a: Record<string, unknown>): Identity => {
  const file = (a["registrationFile"] ?? null) as Record<string, unknown> | null
  const validations = asArray(a["validations"])
  let passed = 0
  let failed = 0
  for (const v of validations) {
    if (v["status"] !== "COMPLETED") continue
    if (Number(v["response"] ?? 0) >= 50) passed += 1
    else failed += 1
  }
  const trusts = file === null ? [] : file["supportedTrusts"]
  return {
    agentId: String(a["id"]),
    chainId: Number(a["chainId"] ?? 0),
    owner: lower(a["owner"]) ?? "",
    agentWallet: lower(a["agentWallet"]),
    name: file === null ? null : str(file["name"]),
    active: file === null ? null : boolOrNull(file["active"]),
    x402Support: file === null ? null : boolOrNull(file["x402Support"]),
    ens: file === null ? null : str(file["ens"]),
    supportedTrusts: Array.isArray(trusts) ? (trusts as Array<string>) : [],
    validationsPassed: passed,
    validationsFailed: failed
  }
}

export const synthesize = (args: {
  readonly address: string
  readonly identities: unknown
  readonly attestations: unknown
  readonly sources: ReadonlyArray<Source>
}): Assessment => {
  const address = args.address.toLowerCase()
  const idRoot = (args.identities ?? {}) as Record<string, unknown>
  const raw = [...asArray(idRoot["asWallet"]), ...asArray(idRoot["asOwner"])]

  const byId = new Map<string, Identity>()
  for (const a of raw) {
    const identity = toIdentity(a)
    if (!byId.has(identity.agentId)) byId.set(identity.agentId, identity)
  }
  const identities = [...byId.values()]

  const flags = new Set<string>()
  if (identities.length === 0) flags.add("no-erc8004-identity")
  for (const i of identities) {
    if (i.validationsFailed > 0) flags.add("validation-failed")
    if (i.active === false) flags.add("registration-inactive")
    if (i.x402Support === false) flags.add("x402-unsupported")
    if (i.agentWallet !== null && i.agentWallet !== i.owner) flags.add("wallet-differs-from-owner")
  }

  // The counterparty's own addresses, so praise it wrote about itself does not count.
  const selves = new Set<string>([address])
  for (const i of identities) {
    selves.add(i.owner)
    if (i.agentWallet !== null) selves.add(i.agentWallet)
  }

  const feedbacks = asArray((args.attestations as Record<string, unknown> | null)?.["feedbacks"])
  let attesterSettledCount = 0
  let sawUnbacked = false
  for (const f of feedbacks) {
    if (f["isRevoked"] === true) {
      flags.add("feedback-revoked")
      continue
    }
    const client = lower(f["clientAddress"]) ?? ""
    if (selves.has(client)) {
      flags.add("self-attested")
      continue
    }
    const file = (f["feedbackFile"] ?? null) as Record<string, unknown> | null
    const tx = file === null ? null : str(file["proofOfPaymentTxHash"])
    if (tx === null) {
      sawUnbacked = true
      continue
    }
    attesterSettledCount += 1
  }
  if (identities.length > 0 && attesterSettledCount === 0) flags.add("unattested-no-proof-of-payment")
  else if (sawUnbacked) flags.add("unattested-no-proof-of-payment")

  const contradictions = CONTRADICTION_CODES.filter((c) => flags.has(c))
  const verdict = contradictions.some((c) => REFUSING.has(c))
    ? "refuse"
    : contradictions.length > 0
      ? "manual-review"
      : "allow"

  return { address, verdict, identities, attesterSettledCount, contradictions, sources: args.sources }
}
```

```ts
 * ARCADE in USDC on ARC (eip155:5042002); ARCADE pays The Graph in USDC on BASE
 * (eip155:8453), because The Graph's x402 gateway settles on Base and there is no Arc option.

export type Runner = (cmd: ReadonlyArray<string>) => Promise<{ code: number; stdout: string }>

const spawnSecurity: Runner = async (cmd) => {
  const p = Bun.spawn([...cmd], { stdout: "pipe", stderr: "ignore" })
  const stdout = await new Response(p.stdout).text()
  const code = await p.exited
  return { code, stdout }
}

/**
 * Keychain first on macOS, env second for Linux CI. `/usr/bin/security` by absolute path
 * because the sandbox builds PATH from scratch (packages/runner/src/exec.ts:40-45), and the
 * service name is overridable so the e2e script can prove the fail-closed path by pointing at
 * an item that does not exist — without deleting the real one.
 */
export const readPayerKey = async (
  env: Record<string, string | undefined>,
  run: Runner = spawnSecurity
): Promise<string> => {
  const service = env["GRAPH_X402_KEYCHAIN_SERVICE"] ?? DEFAULT_KEYCHAIN_SERVICE
  if (process.platform === "darwin") {
    const r = await run(["/usr/bin/security", "find-generic-password", "-s", service, "-w"]).catch(() => ({ code: 1, stdout: "" }))
    const key = r.stdout.trim()
    if (r.code === 0 && /^0x[0-9a-fA-F]{64}$/.test(key)) return key
  }
  const fromEnv = (env["GRAPH_X402_PAYER_KEY"] ?? "").trim()
  if (/^0x[0-9a-fA-F]{64}$/.test(fromEnv)) return fromEnv
  throw new Error(
    `graph payer key unavailable: no keychain item "${service}" and no GRAPH_X402_PAYER_KEY. ` +
      `Store one with: security add-generic-password -s ${service} -a arcade -w`
  )
}

export interface PaidResult {
  readonly data: Record<string, unknown>
  readonly paymentTx: string | null
}
export type PaidQuery = (args: {
  readonly subgraphId: string
  readonly document: string
  readonly variables: Record<string, unknown>
}) => Promise<PaidResult>

/**
 * Runs one paid GraphQL query over x402. The Base settlement hash is reported back by the
 * gateway in `x-payment-response` (x402 v2); it is captured opportunistically by wrapping
 * fetch for the duration of the call, and its absence is `null`, never a failure — the
 * facts were still bought and paid for.
 */
export const makePaidQuery = (privateKey: string): PaidQuery => {
  return async ({ subgraphId, document: doc, variables }) => {
    const { createGraphQuery } = await import("@graphprotocol/client-x402")
    const realFetch = globalThis.fetch
    let paymentTx: string | null = null
    process.env["X402_PRIVATE_KEY"] = privateKey
    process.env["X402_CHAIN"] = "base"
    try {
      globalThis.fetch = (async (input: RequestInfo | URL, init?: RequestInit) => {
        const res = await realFetch(input, init)
        const header = res.headers.get("x-payment-response")
        if (header !== null) {
          try {
            const decoded = JSON.parse(Buffer.from(header, "base64").toString("utf8")) as { transaction?: string }
            if (typeof decoded.transaction === "string") paymentTx = decoded.transaction
          } catch {
            // A header we cannot parse is not a reason to lose a query we already paid for.
          }
        }
        return res
      }) as typeof fetch

      const query = createGraphQuery({ endpoint: `${GATEWAY_BASE}${subgraphId}`, chain: "base" })
      const result = (await query(doc, variables)) as { data?: Record<string, unknown>; errors?: Array<{ message?: string }> }
      if (result.errors !== undefined && result.errors.length > 0) {
        throw new Error(`graph query errors: ${result.errors.map((e) => e.message ?? "?").join("; ")}`)
      }
      const data = result.data ?? (result as unknown as Record<string, unknown>)
      const meta = data["_meta"] as { hasIndexingErrors?: boolean } | undefined
      if (meta?.hasIndexingErrors === true) throw new Error("upstream subgraph reports indexing errors")
      return { data, paymentTx }
    } finally {
      globalThis.fetch = realFetch
      delete process.env["X402_PRIVATE_KEY"]
      delete process.env["X402_CHAIN"]
    }
  }
}
```

```ts
/**
 * counterparty-graph — the seller's cost of goods is on another chain.
 *
 * The buyer paid $0.05 in USDC on ARC. To earn it this process spends up to $0.02 of its own
 * USDC on BASE, buying two queries from The Graph's x402 gateway at a cent each, and returns
 * a decision. It is not a GraphQL proxy: no row this process reads is ever handed back.
 *
 * FAIL-CLOSED. Every failure path — no payer key, a refused 402, a gateway error, an
 * upstream subgraph with indexing errors, or a synthesised object that does not satisfy this
 * skill's own outputSchema — writes `{stopReason: "refusal"}` with NO `output` key and exits
 * 0. `shouldSettle` (packages/core/src/job.ts) requires schema-valid, non-empty output and a
 * non-refusal stop reason, so the hub broadcasts nothing and the buyer's balance is
 * untouched. That is the demo beat: remove the key, and Arc never settles.
 */
import { assessAddressSchemaOk } from "./validate-output.ts"
import {
  AGENT0_BASE_SUBGRAPH_ID, GATEWAY_BASE, PAYMENT_CHAIN, QUERY_COST_ATOMIC,
  document, makePaidQuery, readPayerKey, type PaidQuery
} from "./graph-client.ts"
import { synthesize, type Assessment, type Source } from "./synthesize.ts"

const IDENTITIES = document("identities")
const ATTESTATIONS = document("attestations")

const sourceOf = (name: string, data: Record<string, unknown>, paymentTx: string | null): Source => {
  const meta = data["_meta"] as { block?: { number?: number } } | undefined
  return {
    name,
    endpoint: `${GATEWAY_BASE}${AGENT0_BASE_SUBGRAPH_ID}`,
    subgraphId: AGENT0_BASE_SUBGRAPH_ID,
    block: Number(meta?.block?.number ?? 0),
    chain: PAYMENT_CHAIN,
    costAtomic: QUERY_COST_ATOMIC,
    paymentTx
  }
}

/** Pure orchestration over an injected query so every branch is testable without spending. */
export const assess = async (
  input: { readonly address: string },
  deps: { readonly query: PaidQuery }
): Promise<Assessment> => {
  const address = input.address.toLowerCase()

  const first = await deps.query({ subgraphId: AGENT0_BASE_SUBGRAPH_ID, document: IDENTITIES, variables: { address } })
  const sources: Array<Source> = [sourceOf("agent0-identities", first.data, first.paymentTx)]

  const agentIds = [
    ...(Array.isArray(first.data["asWallet"]) ? (first.data["asWallet"] as Array<{ id: string }>) : []),
    ...(Array.isArray(first.data["asOwner"]) ? (first.data["asOwner"] as Array<{ id: string }>) : [])
  ].map((a) => a.id)
  const uniqueIds = [...new Set(agentIds)]

  // No identity means no attestations can exist. Buying the second query anyway would spend a
  // cent to learn nothing — the seller's margin is the point of this listing.
  if (uniqueIds.length === 0) {
    return synthesize({ address, identities: first.data, attestations: {}, sources })
  }

  const second = await deps.query({ subgraphId: AGENT0_BASE_SUBGRAPH_ID, document: ATTESTATIONS, variables: { agentIds: uniqueIds } })
  sources.push(sourceOf("agent0-attestations", second.data, second.paymentTx))

  return synthesize({ address, identities: first.data, attestations: second.data, sources })
}

const refuse = (reason: string): never => {
  process.stdout.write(JSON.stringify({ stopReason: "refusal", error: reason }))
  process.exit(0)
}

const main = async (): Promise<void> => {
  const raw = await Bun.stdin.text()
  let job: { input?: { address?: string } }
  try {
    job = JSON.parse(raw) as { input?: { address?: string } }
  } catch {
    return refuse("stdin was not JSON")
  }
  const address = job.input?.address
  if (typeof address !== "string" || !/^0x[a-fA-F0-9]{40}$/.test(address)) {
    return refuse("input.address must be a 0x-prefixed 20-byte address")
  }

  let key: string
  try {
    key = await readPayerKey(process.env)
  } catch (e) {
    // The message names the missing keychain item; it never contains a key.
    return refuse(e instanceof Error ? e.message : "graph payer key unavailable")
  }

  let assessment: Assessment
  try {
    assessment = await assess({ address }, { query: makePaidQuery(key) })
  } catch (e) {
    console.error("counterparty-graph: upstream failed:", e instanceof Error ? e.message : e)
    return refuse(`the Graph query could not be completed: ${e instanceof Error ? e.message : "unknown"}`)
  }

  // Last gate: validate our own output against our own contract before claiming success.
  if (!assessAddressSchemaOk(assessment)) return refuse("synthesised output did not satisfy outputSchema")

  process.stdout.write(JSON.stringify({ output: assessment, stopReason: "end_turn" }))
}

if (import.meta.main) {
  main().catch((e) => refuse(e instanceof Error ? e.message : "unhandled failure"))
}
```

# counterparty-graph

**A listing on ARCADE, sold for $0.05 per call in USDC on Arc. Its cost of goods is $0.02 in
USDC on Base.** That sentence is the whole design.

## What it does

Given one address, it answers a question a block explorer cannot: *has anyone actually paid
this counterparty and said so on chain, and does anything they claim contradict the record?*

1. Buys **who this address is** — every ERC-8004 agent whose `owner` or `agentWallet` is that
   address, with its registration file (`name`, `active`, `x402Support`, `supportedTrusts`,
   `ens`) and its ValidationRegistry outcomes.
2. If any identity exists, buys **what its paying customers said** — non-revoked
   ReputationRegistry feedback, with the off-chain envelope's `proofOfPayment*` fields.
3. Joins the two and returns a decision.

It returns **a verdict, never rows**. No GraphQL response is passed through. A buyer who
wanted rows could buy them from the gateway for a cent themselves; what this sells is the
join, the rules, and the contradictions that justify the answer.

## Output

```json

                   "name": "…", "active": true, "x402Support": true, "ens": "…",
```

## Fail-closed

Any failure — missing payer key, an unfunded payer, a refused 402, a gateway error, an
upstream subgraph reporting indexing errors, or a synthesised object that does not satisfy
this skill's own `outputSchema` — produces `{"stopReason":"refusal"}` with **no `output`
key**. ARCADE settles only on schema-valid, non-empty, non-refused output, so the buyer's
authorization is never broadcast and their balance is untouched.

The interesting consequence, and it is a real one: the Graph queries are paid for **before**
the output check runs, so a seller can spend two cents on Base and earn nothing on Arc. That
is what it costs to have "we never broadcast on failure" be true from the buyer's side.
Remove the keychain item and no Base spend happens either — the process refuses before it
pays.

## Not a proxy

- No caller-supplied GraphQL reaches the gateway. The two documents in `queries/` are files
  in this repo, sent verbatim; the only caller-controlled value is the address, bound as a
  typed variable.
- No gateway response is returned to the caller. `synthesize.ts` reads the rows and emits a
  verdict, a count, a contradiction list and provenance.
- The gateway API key model is not used, so no shared key can be exfiltrated: each query is
  paid for individually with a key that only holds cents.

```ts
 * purpose: a risk note that can be talked UP by a third-party signal is a risk note an

export const combineVerdict = (
```

- [ ] **Step 1: Write the script**

```bash
#!/bin/bash
#
# e2e-graph-cogs.sh — the cost of goods is real, on a different chain, and removing the
# means to pay it stops the Arc settlement.
#
# Half one: buy `counterparty-graph` on Arc. Assert the receipt settled with a tx, and assert
# the payer's USDC balance on BASE fell by exactly the number of queries times one cent. The
# balance delta is the evidence rather than a BaseScan API call, because it needs no API key
# and it cannot be faked by reading a receipt the seller wrote.
#
# Half two: point the skill at a keychain item that does not exist. Assert the job does NOT
# settle, no Arc tx exists, and the Base balance is unchanged — the refusal happens before
# any money moves on either chain.
#
# Requires: hub + runner running per docs/runbook.md, a buyer key with Arc testnet USDC, and
# the `graph-x402-payer` keychain item holding a Base-mainnet key funded with USDC.
set -eu

HUB="${HUB:-http://localhost:8787}"
ADDRESS="${ADDRESS:-0x79DC34E41B2b591078d3dE222C43EcaaBD52FcCB}"
BASE_RPC="${BASE_RPC:-https://mainnet.base.org}"
BASE_USDC="0x833589fcd6edb6e08f4c7c32d4f71b54bda02913"
KEYCHAIN_SERVICE="${GRAPH_X402_KEYCHAIN_SERVICE:-graph-x402-payer}"
PAYER="${GRAPH_X402_PAYER_ADDRESS:?set to the Base address of the graph-x402-payer key (public address only, never the key)}"
FAIL=0

# balanceOf(address) = 0x70a08231, 6-decimal USDC on Base.
base_balance() {
  local padded="000000000000000000000000${PAYER#0x}"
  local hex
  hex=$(curl -s "$BASE_RPC" -H 'content-type: application/json' \
    -d "{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"eth_call\",\"params\":[{\"to\":\"$BASE_USDC\",\"data\":\"0x70a08231${padded}\"},\"latest\"]}" \
    | python3 -c 'import json,sys; print(json.load(sys.stdin)["result"])')
  python3 -c "print(int('$hex', 16))"
}

echo "== half one: the seller pays for its inputs =="
BEFORE=$(base_balance)
echo "payer $PAYER USDC on Base before: $BEFORE atomic (https://basescan.org/address/$PAYER)"

OUT=$(bun run arcade-buy counterparty-graph \
  --input "{\"address\":\"$ADDRESS\"}" --max-amount 0.06 --json)
echo "$OUT" | jq .

SETTLE_TX=$(echo "$OUT" | jq -r '.receipt.settleTx // empty')
SETTLED=$(echo "$OUT" | jq -r '.receipt.settled // false')
VERDICT=$(echo "$OUT" | jq -r '.output.verdict // empty')
QUERIES=$(echo "$OUT" | jq -r '.output.sources | length')

if [ "$SETTLED" != "true" ] || [ -z "$SETTLE_TX" ]; then
  echo "FAIL: expected a settled receipt with a tx"; FAIL=1
else
  echo "PASS: settled on Arc  https://testnet.arcscan.app/tx/$SETTLE_TX"
fi
[ -n "$VERDICT" ] || { echo "FAIL: no verdict in the output"; FAIL=1; }
echo "verdict=$VERDICT  graph queries bought=$QUERIES"

AFTER=$(base_balance)
SPENT=$((BEFORE - AFTER))
EXPECTED=$((QUERIES * 10000))
echo "payer USDC on Base after:  $AFTER atomic   spent: $SPENT atomic (expected $EXPECTED)"
if [ "$SPENT" != "$EXPECTED" ]; then
  echo "FAIL: Base spend $SPENT != $QUERIES x 10000"; FAIL=1
else
  echo "PASS: bought $QUERIES queries for \$0.0$((EXPECTED / 10000 )) on Base while settling on Arc"
fi

echo
echo "== half two: remove the key, and nothing settles anywhere =="
BEFORE2=$(base_balance)
OUT2=$(GRAPH_X402_KEYCHAIN_SERVICE="${KEYCHAIN_SERVICE}-absent" GRAPH_X402_PAYER_KEY= \
  bun run arcade-buy counterparty-graph \
  --input "{\"address\":\"$ADDRESS\"}" --max-amount 0.06 --json || true)
echo "$OUT2" | jq .

SETTLED2=$(echo "$OUT2" | jq -r '.receipt.settled // false')
TX2=$(echo "$OUT2" | jq -r '.receipt.settleTx // empty')
AFTER2=$(base_balance)

if [ "$SETTLED2" = "true" ] || [ -n "$TX2" ]; then
  echo "FAIL: a failed job settled on Arc — this is the one thing that must never happen"; FAIL=1
else
  echo "PASS: unsettled, no Arc tx, buyer balance untouched"
fi
if [ "$BEFORE2" != "$AFTER2" ]; then
  echo "FAIL: Base USDC moved without a key ($BEFORE2 -> $AFTER2)"; FAIL=1
else
  echo "PASS: no Base spend either — the refusal happens before any money moves"
fi

echo
[ "$FAIL" = "0" ] && echo "ALL PASS" || echo "FAILURES ABOVE"
exit $FAIL
```

If `bun run arcade-buy` does not accept `--json`, read the same fields from the poll URL it
