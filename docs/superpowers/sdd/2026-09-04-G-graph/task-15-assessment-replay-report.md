# G15S complete historical assessment artifact

The [assessment-replay brief](task-15-assessment-replay-brief.md) adds a bounded
private artifact over complete retained query evidence. The original consumer
only exports its existing result decoder under an inert alias. Its key lookup,
query sequence, synthesis and result behavior are unchanged; no original payment
client, synthesis policy or schema logic changes.

The harness requires original current-source identity, an unclaimed global
ledger and zero derived unresolved reservations. It reconstructs the fixed
identity query from the pinned source document and reads its qualified cache.
Only when the original identity selector requires it does it reconstruct and
read the exact pinned attestations query. Each cache and completed balance
journal must match the qualified reservation proof. The original result decoder,
identity selector, synthesis and schema validate the conservative assessment;
indexed data never supplies trusted validators or verified settlement proofs.

An exclusive assessment directory holds result.json and commit.json, with0700
directory/0600 files, fsync, bounded canonical bytes, private single-link reads,
hash/marker correlation, repeated source/history/inventory/identity checks and
one shared monotonic five-second local IO acknowledgement deadline. Supplied
output must exactly equal retained-data reconstruction before creating files.
Stored time cannot predate query-cache storage or balance-journal completion.
Incomplete/late/uncertain writes retain artifacts and claims; no overwrite,
automatic repair, claim takeover, refund or new operational namespace.

Read-only replay validates the complete immutable artifact against fresh retained
history and checks its bytes again after final history validation. It returns
deeply immutable output, original source transaction/cost/Graph block, capture/
cache/journal times, proof references and unchanged quota counts. Labels are
historical-assessment-replay, cacheHits1 or2, newPaidQueries0 and
freshConsumerRunfalse. It never enters runGraphJob, assess, a fake-key path,
Keychain, signer or transport. Missing required second-query evidence refuses
while retaining the successful first query; unknown later exposure blocks replay.

These are current-source retained consistency checks, not independent network
authentication, malicious-owner rewrite resistance, fresh runner execution or
proof that an earlier consumer received its output. The writer accepts supplied
output only by consistency; the synthetic positive fixtures do not become live
payment proof. Old source-version caches cannot silently refresh with new spending.
